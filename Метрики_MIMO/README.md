# Метрики маркетплейсов для контент-менеджера — 20 уроков + 20 тренажёров

Курс-шпаргалка по метрикам маркетплейсов (Wildberries / Ozon) для контент-менеджера:
**20 уроков теории** (Markdown) и **к каждому уроку свой тренажёр** (Excel, 5 заданий с
самопроверкой). Программа построена по воронке карточки: видимость → клики → карточка →
корзина → заказ → выкуп → деньги → реклама → SEO → отзывы → итоговый эффект правок.

## Единый кейс курса

Все 20 уроков и тренажёров идут на одном кейсе, чтобы метрики были связаны между собой:

| Параметр | Значение                                                               |
| -------- | ---------------------------------------------------------------------- |
| SKU      | TRM-500 «Термокружка Arctic 500 мл», бренд Nordvik                     |
| Площадка | Wildberries                                                            |
| Период   | март 2026, 28 дней (4 недели)                                          |
| Воронка  | 120 000 показов → 3 600 кликов → 540 корзин → 378 заказов → 344 выкупа |
| Деньги   | средний чек 1 750 ₽, ASP 1 575 ₽, GMV 661 500 ₽, маржа 27,2%           |
| Реклама  | 27 000 ₽ расхода, 126 заказов, CPO 214,3 ₽, ROAS 8,17, DRR 4,1%        |

## Как пользоваться

1. Урок — это шпаргалка на 5–10 минут: формулы, ориентиры («что хорошо / что плохо»),
   чек-лист рычагов контента, типовые ошибки и разбор на кейсе TRM-500.
2. К уроку приложен тренажёр `Тренажёры/NN_<тема>_тренажер.xlsx` с тремя листами:
   **Условия** (данные), **Задания** (5 задач), **Справка** (формулы).
3. В заданиях ответы вписываются в **жёлтые ячейки** — столбец «Статус» сам показывает
   «OK Верно» / «X Пересчитай» (допуск задания учтён). Правильный ответ подкрашен бледным —
   сначала решите сами; путь расчёта — в столбце «Подсказка».
4. Проценты вводятся числом: `3,0` — это три процента.
5. Порядок изучения — линейный (уроки 1 → 20), по 1–2 урока в день с тренажёром.
