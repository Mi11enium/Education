# Урок 11. Основные метрики PnL

## Абсолютные метрики

### Total PnL
Сумма всех прибылей и убытков.
```python
total_pnl = pnl.sum()
```
- ⚠️ Не учитывает время, риск, просадки.

### Gross Profit / Gross Loss
- **Gross Profit**: сумма всех прибыльных сделок.
- **Gross Loss**: сумма всех убыточных (отрицательная).

### Profit Factor
```
PF = Gross Profit / |Gross Loss|
```

| PF | Интерпретация |
|---|---|
| < 1.0 | Убыточная стратегия |
| 1.0–1.3 | Слабый edge |
| 1.3–2.0 | Хороший edge |
| > 2.0 | Отличный (но проверить overfit) |

⚠️ Profit Factor не учитывает количество сделок и время.

### Avg Win / Avg Loss (Average Win/Loss Ratio)
```
Avg_Win = Gross_Profit / N_wins
Avg_Loss = Gross_Loss / N_losses  (отрицательное)
W/L = |Avg_Win / Avg_Loss|
```

### Win Rate
```
WR = N_wins / N_total
```

### Expectancy (Мат. ожидание на сделку)
```
E = WR × Avg_Win + (1 - WR) × Avg_Loss
```

- Главная метрика стратегии.
- E > 0 → edge есть.

## Количество сделок
**Минимум 30–100 сделок** для статистической значимости. Желательно 200+.

## Длительность

### Avg Trade Duration
Среднее время в позиции.

### Max Holding Period
Максимальное время удержания.

## Полезные производные метрики

### Payoff Ratio
```
Payoff = Avg_Win / |Avg_Loss|
```

### Expectancy per Trade
```
E = (WR × Payoff - (1 - WR)) × |Avg_Loss|
```

### Total R Multiple
Сумма R-multiple сделок, где R = PnL / Risk.
- Позволяет сравнивать стратегии с разным риском.

## Пример
Стратегия за 100 сделок:
- Wins: 55, суммарно $5500 (avg $100).
- Losses: 45, суммарно $2250 (avg $50).
- Total PnL: $3250.
- Profit Factor: 5500/2250 = **2.44**.
- Win Rate: 55%.
- W/L: 2.0.
- Expectancy: 0.55×100 + 0.45×(-50) = **$32.5/сделку**.

## PnL по времени

### Ежемесячный PnL
- Диверсификация рисков.
- Стабильность.
- Equity curve должна быть восходящей.

### Распределение по дням недели / часам
- Некоторые стратегии лучше в определённые дни.

## Стресс-метрики
- **Max Consecutive Losses**: максимум убытков подряд.
- **Max Time to Recovery**: макс. время восстановления после DD.
- **Time in Drawdown**: % времени под водой.

## Анализ распределения
- **Histogram PnL** — есть ли длинный хвост.
- **Q-Q plot** vs. нормальное — отклонения.
- **Skewness**: асимметрия.
- **Kurtosis**: эксцесс.
