# Урок 7. Дисперсия и стандартное отклонение

## Зачем алготрейдеру дисперсия
Дисперсия определяет **разброс результатов**. Даже при положительном EV одна плохая сделка может уничтожить много заработка. Дисперсия — главный враг психологической устойчивости.

## Определения

### Дисперсия
```
Var(X) = E[(X - E[X])²] = E[X²] - (E[X])²
```

### Стандартное отклонение
```
σ = sqrt(Var(X))
```

### Выборочная оценка
```
σ_sample = sqrt( Σ (x_i - mean)² / (N-1) )
```

⚠️ `ddof=1` (делить на N-1) — выборочная дисперсия. По умолчанию в numpy/pandas тоже.

## В трейдинге

### Volatility vs. Std of PnL
- **Volatility** — обычно σ доходности актива (annualized ~15–30% для акций).
- **Std of PnL** — σ отдельных сделок.
- Связаны: PnL ≈ Position × Return.

### Пример
- 1 лот = $1000 движения.
- 1 ATR дневной = 200 пунктов.
- σ дневного PnL ≈ $200 × 1 = $200.
- За год (250 торговых дней) σ_annual ≈ $200 × sqrt(250) ≈ $3162.

## Распределение PnL

### Нормальное ли?
❌ Финансовые PnL **не нормальны**:
- **Толстые хвосты** (fat tails) — экстремальные движения чаще, чем предсказывает нормальное.
- **Отрицательная асимметрия** — большие убытки встречаются чаще больших прибылей.
- **Эксцесс** (kurtosis) > 3.

### Лучшие распределения
- **t-распределение Стьюдента** — толстые хвосты.
- **Cauchy** — очень толстые хвосты.
- **Pareto** — для хвостов.

## Влияние дисперсии на PnL

### Var(PnL_total)
При N **независимых** сделок:
```
Var(PnL_total) = N × Var(PnL_per_trade)
```

### Std(PnL_total)
```
σ_total = sqrt(N) × σ_per_trade
```

### Отношение сигнал/шум
```
SNR = EV / σ_per_trade
```

Чем выше SNR, тем **быстрее** реализуется edge. Низкий SNR = нужны тысячи сделок.

### Пример
- EV = $50, σ = $500.
- SNR = 0.1.
- За 100 сделок: прибыль $5000, σ_total = $5000.
- Это значит: ±2σ = ±$10 000. Плохо предсказуемо.
- За 10000 сделок: прибыль $500 000, σ_total = $50 000. Хорошо.

## Автокорреляция сделок

### Проблема
Сделки часто **не независимы**:
- Стратегия сериями открывает/закрывает.
- После убытка — убыток (stops cascade).
- Кластеризация волатильности.

### Метрики
- **ACF (Autocorrelation Function)** — лаг-1 корреляция.
- **Ljung-Box test** — статистическая значимость.

### Если автокорреляция > 0
- Эффективный размер выборки меньше.
- Нужно **больше сделок** для уверенности.

## Volatility clustering
**GARCH-эффект**: периоды высокой волатильности сменяются тишиной.
- Вчерашний σ влияет на сегодняшний.
- Учитывайте в риск-моделях (VaR).

## Практические выводы

### 1. Не путайте EV и реальную прибыль
Маленький EV + большая дисперсия = огромные просадки.

### 2. Считайте σ в бэктесте
Это даёт реалистичное ожидание просадок.

### 3. Уменьшайте дисперсию
- Снижать позицию.
- Увеличивать частоту (закон больших чисел).
- Диверсифицировать стратегии.

### 4. Используйте robust оценки
- **MAD** (median absolute deviation) вместо σ.
- **Interquartile range** (IQR).
