## Виды API

### 1. REST API
- HTTP-запросы (GET, POST).
- ✅ Простой, удобный.
- ❌ Latency 50–500 мс.
- Пример: T-Invest API, IBKR Client Portal API.

### 2. WebSocket / Streaming
- Постоянное соединение, real-time updates.
- ✅ Быстрый, push.
- ❌ Сложнее поддерживать.

### 3. FIX (Financial Information eXchange)
- Биржевой стандарт.
- ✅ Быстрый, надёжный.
- ❌ Сложный, нужен FIX-движок.
- Plaza2, TWIME, FIX 4.4.

### 4. Нативные биржевые протоколы
- ASTS Bridge, Plaza2, TWIME (для MOEX).
- Rithmic, CQG (для CME).
- Минимальная latency.

## Серверная инфраструктура

### Варианты
- **VPS у брокера** (colocation) — 1–5 мс до биржи.
- **VPS в дата-центре** (Amazon, Google Cloud, Hetzner) — 5–50 мс.
- **Домашний ПК** — 50–500 мс.

### Минимальные требования для среднечастотной стратегии
- CPU: 2–4 ядра.
- RAM: 8–16 GB.
- SSD: 100+ GB.
- Стабильный интернет (с резервным каналом).

## Подводные камни
- ❌ Брокер меняет API — ломается робот.
- ❌ Лимиты на API (rate limits).
- ❌ Задержки в исполнении (slippage).
- ❌ Отмена ордеров на волатильности.
- ❌ Margin call при гэпах.

## Юридическое
- Уведомить брокера, что вы — алготрейдер (если требуется).
- Лицензии (для маркет-мейкинга в РФ — проф. участник).
- Налоги: учитывайте сделки, платите НДФЛ.
