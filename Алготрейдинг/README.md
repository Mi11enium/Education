## 🚀 Как использовать

1. **Новичкам**: проходите уроки последовательно с 1 по 50.
2. **Практикам**: открывайте чек-лист (урок 50) перед запуском.
3. **Исследователям**: уроки 21–28 — про бэктест, 29–37 — про оптимизацию.
4. **Production**: уроки 47–49 — для запуска и поддержки.
