# Урок 19. Комиссии и структура издержек

## Зачем знать
Комиссии могут **уничтожить** edge стратегии. Особенно в скальпинге и интрадей-торговле.

## Структура издержек

### 1. Комиссия брокера
- **Per contract**: $X за контракт.
- **Per share**: $X за акцию.
- **% от оборота**: для крипты, forex.

### Примеры (CME)
- E-mini S&P 500 (ES): ~$1.18 / сторона = $2.36 round-trip.
- E-mini NQ (NQ): ~$1.18 / сторона.
- E-mini RTY: ~$1.05 / сторона.

### Примеры (MOEX, 2024)
- RI (RTS): ~1.5 / сторона.
- SI (USD/RUB): ~1.5 / сторона.
- BR (нефть): ~2 / сторона.
- ⚠️ Уточняйте актуальные тарифы.

### 2. Биржевой сбор
- Часто входит в комиссию брокера.
- Уточняйте — двойное начисление бывает.

### 3. Клиринг
- Обычно включён.

### 4. Регуляторные сборы
- SEC, FINRA (США).
- Минимальны, но бывают.

## Round-Trip vs. Per Side

### Round-Trip
Полная стоимость: вход + выход.
- ES: ~$2.36 RT.

### Per Side
За одну сторону.
- ES: ~$1.18 per side.

⚠️ **Всегда считайте RT** (round-trip) — это ваши реальные издержки на сделку.

## Типичная структура для алго

### Активный скальпер
- 50 сделок/день.
- ES × 50 × $2.36 = $118/день комиссий.
- $3000/мес ≈ 30% от депозита $10k.

### Свинг-трейдер
- 5 сделок/неделю.
- ES × 5 × $2.36 = ~$12/неделю.
- ~$50/мес.

## Комиссия в % от PnL

### Формула
```
Commission_pct = (Total_Commission / Total_PnL) × 100%
```

### Что должно быть
- <10% — отлично.
- 10–20% — нормально.
- 20–40% — много.
- >50% — edge не оправдывает.

### Пример
- 100 сделок.
- PnL gross: $10 000.
- Commission: $1500.
- Net: $8500.
- Commission %: 15% — нормально.

## Скрытые комиссии

### 1. Bid-Ask Spread
- Не всегда комиссия, но издержка.
- Лимитный ордер → платите спредом.

### 2. Slippage (см. урок 20)
- Реальная цена хуже ожидаемой.
- По сути — скрытая комиссия.

### 3. Borrow fee (для шортов акций)
- Плата за «аренду» акции.
- 0.5–5% годовых.

### 4. Financing (фьючерсы)
- Margin interest, если не оплачен.
- Mark-to-market.

## Влияние на стратегию

### Break-even winrate
Минимальный WR, при котором стратегия прибыльна:
```
BE_WR = 1 / (1 + W/L_ratio)
```

### С учётом комиссий
```
BE_WR_with_costs = (Cost_per_trade + Avg_Loss) / (Avg_Win - Avg_Loss + Cost_per_trade)
```

### Пример
- Avg_Win = $200, Avg_Loss = $100, W/L = 2.
- BE_WR (без комиссий) = 1/(1+2) = 33.3%.
- С комиссией $10: BE_WR = (10+100)/(200-100+10) = **50.5%**.

⚠️ Комиссия подняла BE_WR с 33% до 50%!

## Как минимизировать комиссии

### 1. Выбор брокера
- Сравните effective rate (не headline).
- Ищите volume discounts.
- Introductory offers.

### 2. Объём
- Брокеры дают скидки за объём.
- Tiered pricing.

### 3. Marketable limits
- Не платите за spread через лимитки.
- Aggressive limits = близко к маркет-ордеру, но с контролем.

### 4. Группировка сделок
- Вместо 10 лимитных — 1 рыночный.
- Зависит от стратегии.

### 5. Выбор тарифа
- Per-trade vs. subscription.
- Если много сделок — subscription может быть выгоднее.

## Запись комиссий в бэктесте

```python
def apply_commission(pnl, commission_per_side, n_contracts):
    total_commission = 2 * commission_per_side * n_contracts
    return pnl - total_commission
```

⚠️ Никогда не публикуйте бэктест **без** комиссий. Результаты завышены в 2–5 раз.
