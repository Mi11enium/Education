# Урок 1. Что такое алготрейдинг

## Определение
**Алготрейдинг (algorithmic trading)** — это автоматизированная торговля на финансовых рынках с помощью заранее запрограммированных алгоритмов. Робот сам принимает решения о входе/выходе из позиции без участия человека.

## Виды алготрейдинга

### 1. HFT (High-Frequency Trading)
- Миллионы сделок в секунду.
- Latency в микросекундах.
- Colocation, FPGA.
- ❌ Не для индивидуальных трейдеров.

### 2. Систематический трейдинг
- Средне- и низкочастотные стратегии.
- Удержание позиций: секунды → дни.
- ✅ **Фокус этой шпаргалки** (фьючерсы).

### 3. Market making
- Постоянные котировки bid/ask.
- Заработок на спреде.
- Требует лицензию/инфраструктуру.

### 4. Арбитраж
- Межбиржевой, фьючерс-спот, календарный.
- Низкорисковый, но капиталоёмкий.

## Преимущества алготрейдинга
✅ **Дисциплина** — нет эмоций, нет revenge trading.
✅ **Скорость** — реакция в миллисекунды.
✅ **Масштабируемость** — один робот торгует много инструментов.
✅ **Тестируемость** — бэктест на истории.
✅ **Воспроизводимость** — стратегия работает одинаково 24/7.

## Риски алготрейдинга
❌ **Технические сбои** — баги, разрывы соединения, биржевые сбои.
❌ **Overfitting** — стратегия работает на бэктесте, но не в реале.
❌ **Regime change** — рынок меняется, стратегия перестаёт работать.
❌ **Катастрофические потери** — «чёрный лебедь», гэпы, flash crash.
❌ **Операционный риск** — забытый в продакшн код, ошибки в позиции.

## Алготрейдинг vs. ручной трейдинг

| Параметр  | Алго                         | Ручной           |
| --------- | ---------------------------- | ---------------- |
| Эмоции    | Нет                          | Есть             |
| Скорость  | Миллисекунды                 | Секунды-минуты   |
| Масштаб   | 100+ инструментов            | 1–5              |
| Бэктест   | Да                           | Нет              |
| Адаптация | Медленная                    | Быстрая          |
| Требует   | Программирование, статистика | Психология, опыт |
|           |                              |                  |

## Кто такой алготрейдер
Алготрейдер — это **исследователь + инженер**:
- Понимание рынка (структура, микроструктура, ликвидность).
- Математика и статистика (распределения, временные ряды, тесты).
- Программирование (Python, C++, иногда Rust).
- Управление рисками.
- DevOps и мониторинг.

## Долгосрочная прибыль — основа
В алготрейдинге **математическое ожидание (edge)** — единственный источник прибыли.
Без edge робот рано или поздно потеряет деньги из-за комиссий и проскальзывания.
