# Урок 10. Проверка гипотез в трейдинге

## Зачем
Прежде чем ставить реальные деньги на стратегию, нужно доказать, что её edge **статистически значим**, а не случайность.

## Фреймворк проверки гипотез

### H0 (нулевая гипотеза)
- PnL стратегии = 0 (нет edge).

### H1 (альтернативная)
- PnL > 0 (есть edge).

### Уровень значимости α
- Обычно 0.05.
- Вероятность ошибочно отвергнуть H0 = 5%.

### P-value
- Вероятность получить наблюдаемое (или более экстремальное) при H0.
- p < α → отвергаем H0.

## Типичные гипотезы в алготрейдинге

1. **Edge > 0** (mean PnL > 0).
2. **Sharpe > 0** (риск-скорректированная прибыль).
3. **Возврат к среднему** (в спреде).
4. **Корреляция = 0** (нет лишних зависимостей).
5. **Два распределения PnL одинаковы** (две стратегии).

## Методы проверки

### 1. t-тест на среднее
```python
from scipy import stats
t, p = stats.ttest_1samp(pnl, 0)
```
- H0: μ = 0.
- p < 0.05 → отвергаем.

### 2. Wilcoxon signed-rank (непараметрический)
```python
from scipy import stats
stat, p = stats.wilcoxon(pnl)
```
- ✅ Не требует нормальности.
- H0: median = 0.

### 3. Bootstrap CI
```python
def bootstrap_mean(pnl, n=10000):
    means = [np.mean(np.random.choice(pnl, len(pnl), replace=True)) for _ in range(n)]
    return np.percentile(means, [2.5, 97.5])
```
- 95% CI не содержит 0 → значимо.

### 4. Sign test
```python
from scipy import stats
stat, p = stats.binom_test(np.sum(pnl > 0), len(pnl), 0.5)
```
- H0: P(win) = 50%.
- Не использует величину PnL.

### 5. Sharpe test
```python
from scipy import stats
def sharpe_test(returns, sr=0):
    n = len(returns)
    s = returns.mean() / returns.std() * np.sqrt(252)
    se = np.sqrt((1 + 0.5 * s**2) / n)
    z = (s - sr) / se
    p = 1 - stats.norm.cdf(z)
    return s, p
```

## Проблема множественных тестов

### Ситуация
Вы тестируете 1000 параметров стратегии. Находите «лучший» с p=0.01.
- Это может быть **ложное открытие** (из 1000 тестов 50 будут значимыми случайно).

### Коррекции
1. **Bonferroni**: порог = α / N (слишком жёсткий).
2. **Benjamini-Hochberg (FDR)**: контроль доли ложных открытий.
3. **Holm-Bonferroni**: пошаговый.

### Практический подход
- Разбейте данные на **3 выборки**:
  - In-sample (для подбора параметров).
  - Validation (для отбора между кандидатами).
  - Out-of-sample (для финального теста).
- **Out-of-sample** — самый честный.

## Проблема «p-hacking»

### Что это
Подгонка тестов, выборок, параметров, чтобы получить желаемый p-value.

### Антидот
- **Pre-registration** гипотезы (зафиксировать план до теста).
- **Out-of-sample** test.
- **Walk-forward** validation.

## Практический алгоритм

```
1. Сформулируйте гипотезу.
2. Зафиксируйте выборку (без подглядывания).
3. Примените тест.
4. Сравните p с α (0.05).
5. Сделайте вывод.
6. Повторите на out-of-sample.
```

## Мощность теста (Power)

### Определение
Вероятность отвергнуть H0, когда H1 верна.
```
Power = 1 - β
```
где β — вероятность ошибки II рода.

### Как увеличить
- Больше данных.
- Больший эффект (больше edge).
- Меньше шума (низкая дисперсия).

### В трейдинге
- Часто **низкая мощность** (мало сделок, высокая дисперсия).
- Результат «не значим» не значит «edge нет».

## Bayesian подход (альтернатива)

### Идея
Использовать априорное распределение и обновлять его.

```python
import pymc as pm
with pm.Model() as model:
    mu = pm.Normal('mu', mu=0, sigma=10)
    sigma = pm.HalfNormal('sigma', sigma=10)
    obs = pm.Normal('obs', mu=mu, sigma=sigma, observed=pnl)
    trace = pm.sample()
```

- Получаем распределение edge.
- P(edge > 0 | data).
