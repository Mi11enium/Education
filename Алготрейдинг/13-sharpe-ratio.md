# Урок 13. Коэффициент Шарпа (Sharpe Ratio)

## Что это
**Sharpe Ratio** — главная метрика risk-adjusted доходности.
Показывает, сколько **избыточной** доходности вы получаете на единицу волатильности.

## Формула

```
Sharpe = (E[R] - Rf) / σ_R
```

где:
- `E[R]` — средняя доходность.
- `Rf` — безрисковая ставка (annualized).
- `σ_R` — стандартное отклонение доходности.

## Варианты

### Дневной Sharpe
```
Sharpe_daily = mean(daily_return) / std(daily_return)
```

### Годовой Sharpe
```
Sharpe_annual = Sharpe_daily × sqrt(252)
```

### С поправкой на autocorrelation
Lo (2002) correction:
```
Sharpe_adj = Sharpe × sqrt(1 / (1 + 2 × sum(ρ_lag)))
```

## Интерпретация

| Sharpe Annual | Качество |
|---|---|
| < 0 | Плохо (хуже безрисковой) |
| 0–0.5 | Слабый |
| 0.5–1.0 | Приемлемый |
| 1.0–2.0 | Хороший |
| 2.0–3.0 | Отличный |
| > 3.0 | Подозрительно (overfit или высокий риск) |

⚠️ **Sharpe > 3** на бэктесте — почти всегда переобучение.

## Пример
- Средняя дневная доходность: 0.05%.
- σ дневная: 1%.
- Sharpe дневной = 0.05.
- Sharpe годовой = 0.05 × sqrt(252) = **0.79**.

## Ограничения Sharpe

### 1. Не учитывает хвостовой риск
- Стратегия с редкими катастрофами может иметь хороший Sharpe.
- Sharpe 2 с одним -50% событием ≠ Sharpe 2 без него.

### 2. Чувствителен к окну
- Можно «подогнать» выбор периода.
- Плохо при нестационарности.

### 3. Штрафует upside
- Положительная дисперсия тоже «наказывается».
- Стратегия с большими прибылями и редкими убытками — может иметь низкий Sharpe.

### 4. Плохо для не-нормальных распределений
- Финансовые returns не нормальны.

## Deflated Sharpe Ratio (DSR)

### Идея
Скорректировать Sharpe с учётом:
- Количества попыток (стратегий, параметров).
- Длины выборки.
- Skewness, kurtosis.

### Использование
- Защита от «Sharpe inflation» при множественном тестировании.
- Обязательно при оптимизации параметров.

## Probabilistic Sharpe Ratio (PSR)
Вероятность, что реальный Sharpe > порога:
```python
from scipy.stats import norm
def psr(sr_hat, sr_benchmark, n, skewness, kurtosis):
    se = np.sqrt((1 - skewness*sr_hat + (kurtosis-1)/4 * sr_hat**2) / (n-1))
    return norm.cdf((sr_hat - sr_benchmark) / se)
```

## Минимальный Sharpe для разных стратегий

| Тип | Минимальный Sharpe |
|---|---|
| Скальпинг | 1.5+ |
| Интрадей | 1.0+ |
| Свинг | 0.7+ |
| Позиционная | 0.5+ |

⚠️ Без учёта плеча. С плечом требования ниже.

## Минимальная выборка

### Правило
- 95% CI на Sharpe ширина = 1.96 × SE.
- SE = sqrt((1 + 0.5 × Sharpe²) / N).
- Для Sharpe=1, N=250 (1 год): SE ≈ 0.04, CI: 0.92-1.08.
- Для Sharpe=1, N=60 (3 мес): SE ≈ 0.09, CI: 0.82-1.18.

**Вывод**: меньше 1 года о Sharpe судить рано.
