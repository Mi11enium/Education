# Урок 38. Маржинальный utility и оценка стратегий

## Зачем
Просто «Sharpe = 1.5» не говорит, насколько стратегия ценна для **вашего** портфеля. Нужен utility-подход.

## Utility функция

### CARA (Constant Absolute Risk Aversion)
```
U(W) = -exp(-γ × W)
```

или в эквивалентной форме:
```
E[U(W)] = -exp(-γ × E[W] + 0.5 × γ² × Var(W))
```

где:
- W — итоговое богатство.
- γ — коэффициент неприятия риска.

### Пример
- γ = 2 (средний риск-averse).
- E[W] = $110 000.
- Var(W) = $5 000 000.
- E[U] = -exp(-2 × 110 + 0.5 × 4 × 5000) = -exp(-220 + 10000) ≈ 0.

⚠️ Var доминирует в utility.

## Utility vs. Sharpe

### Sharpe не учитывает
- Размер позиции (leverage).
- Размер счёта.
- Margin constraints.
- Допустимый MaxDD конкретного трейдера.

### Utility учитывает
- ✅ Абсолютный риск.
- ✅ Размер счёта.
- ✅ Margin constraints.

## Оптимальный f (Kelly-fraction)

### Kelly criterion
```
f* = μ / σ²
```

для continuous returns.

### Для стратегии
```
f* = (μ - r) / σ²
```

где r — безрисковая ставка.

### Пример
- μ = 15% годовых.
- σ = 20%.
- f* = 0.15 / 0.04 = **3.75**.

⚠️ Kelly даёт очень агрессивный размер. На практике — 0.25–0.5 × Kelly.

## Оптимальное плечо

### С учётом Kelly
- Target: 0.25–0.5 × Kelly.
- Пример: 0.5 × 3.75 = 1.88 → leverage ~2x.

## Log-utility (для длинных горизонтов)

```
U(W) = log(W)
```

- Лучше для long-term compounding.
- E[U] = E[log(1 + R)] ≈ E[R] - 0.5 × Var(R).

### Сравнение с CRRA
- Log-utility: относительное risk aversion = 1.
- CARA: абсолютное.

## Применение к выбору стратегий

### Алгоритм
1. Определить risk aversion γ.
2. Посчитать utility каждой стратегии.
3. Выбрать с максимальной utility.

```python
def utility(returns, gamma=2):
    wealth = 100000 * np.cumprod(1 + returns)
    final_wealth = wealth[-1]
    var_w = final_wealth**2 * np.var(returns)
    return -np.exp(-gamma * final_wealth + 0.5 * gamma**2 * var_w)
```

## Пример

### Стратегия A
- E[R] = 12%, σ = 8%.
- Sharpe = 1.5.

### Стратегия B
- E[R] = 20%, σ = 18%.
- Sharpe = 1.1.

### У кого лучше utility?
- При γ = 5:
  - A: U ≈ -exp(-5×12 + 0.5×25×64) = -exp(-60 + 800) ≈ 0.
  - B: U ≈ -exp(-5×20 + 0.5×25×324) = -exp(-100 + 4050) ≈ 0.

❌ Обе почти одинаково плохи (utility → 0).

⚠️ Это показывает, что **Sharpe — не всё**. При высокой variance utility стремится к нулю.

## Risk-Return с учётом leverage

### Optimal Leverage
```
L* = Sharpe / (γ × σ_annual)
```

### Пример
- Sharpe = 1.5, σ = 15%, γ = 5.
- L* = 1.5 / (5 × 0.15) = **2.0**.

⚠️ При leverage = 2, итоговая волатильность = 30%. Подходит не всем.

## Portfolio context

### Стратегия в портфеле
- Не оценивайте стратегию изолированно.
- Смотрите на её **долю** в портфеле.
- Диверсификация снижает variance.

### Marginal contribution
- Добавление стратегии к портфелю.
- Увеличивает ли utility?

## Certainty Equivalent

### Определение
Гарантированная сумма, эквивалентная рискованной стратегии.

```
CE = E[W] - 0.5 × γ × Var(W)
```

### Пример
- E[W] = $110k, Var = $5M, γ = 2.
- CE = 110k - 0.5 × 2 × 5000k = 110k - 5000k = **-$4.89M**.

❌ Стратегия разрушает utility.
