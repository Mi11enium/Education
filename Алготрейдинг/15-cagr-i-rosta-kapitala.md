# Урок 15. CAGR, доходность и рост капитала

## Абсолютная доходность

### Total Return
```
R_total = (Final - Initial) / Initial
```

### Пример
- Initial: $100 000.
- Final: $150 000.
- Total Return = 50%.

⚠️ Не учитывает время.

## CAGR (Compound Annual Growth Rate)

### Формула
```
CAGR = (Final / Initial)^(1/years) - 1
```

### Пример
- Initial: $100 000.
- Final: $200 000.
- Период: 3 года.
- CAGR = (200/100)^(1/3) - 1 = **25.99%** в год.

### Зачем нужна
- Позволяет сравнивать стратегии с разным сроком.
- Главная метрика для инвесторов.

### Ограничения
- Не учитывает волатильность пути.
- 30% CAGR с MaxDD 80% — плохо.
- 15% CAGR с MaxDD 5% — хорошо.

## Volatility-Adjusted CAGR

### 1. CAGR / Volatility
```
CAGR_vol = CAGR / σ_annual
```

### 2. CAGR / MaxDD (Calmar)
```
Calmar = CAGR / |MaxDD|
```

### 3. CAGR / VaR
```
CAGR_VaR = CAGR / VaR_95
```

## Геометрическое vs. Арифметическое среднее

### Арифметическое (AMA)
```
AMA = mean(R_i)
```

### Геометрическое (GMA)
```
GMA = (1 + R_total)^(1/N) - 1 = CAGR
```

### Связь
```
AMA ≈ GMA + σ²/2  (для малых σ)
```

### Пример
- AMA = 15%, σ = 30%.
- GMA ≈ 15% - 30²/(2×100) = 15% - 4.5% = **10.5%**.

⚠️ GMA << AMA при высокой волатильности.

## Реинвестирование

### С капитализацией
- PnL реинвестируется.
- Compound effect — экспоненциальный рост.

### Без реинвестирования
- PnL выводится.
- Линейный рост.

⚠️ В бэктесте сравнивайте оба варианта.

## Подводные камни CAGR

### 1. Пересчёт по под-периодам
Год 1: +100%, год 2: -50%.
- Total: 0% (от $100 до $100).
- CAGR: 0%.
- AMA: 25%.
- **AMA > CAGR** — большая волатильность.

### 2. Survivorship bias
CAGR «лучших» стратегий в индустрии — biased.

### 3. Look-ahead bias
Если CAGR считается по будущим данным — некорректно.

## Time-Weighted Return (TWR)

### Зачем
Когда есть пополнения/снятия, TWR отделяет «работу» стратегии от притока капитала.

```python
# Sub-period returns, chain them:
TWR = (1 + R1) × (1 + R2) × ... × (1 + Rn) - 1
```

## MWR (Money-Weighted Return)
Учитывает время и размер вложений. Внутренняя норма доходности (IRR).

## Примеры CAGR для разных стратегий

| Тип | Реалистичный CAGR |
|---|---|
| HFT | 20–50% (с плечом) |
| Скальпинг | 30–100%+ (с плечом) |
| Интрадей | 20–60% (с плечом) |
| Свинг | 10–30% |
| Позиционная | 5–15% |

⚠️ Чем дольше период, тем сложнее поддерживать высокий CAGR.

## Ключевые производные метрики

### Правило 72
```
Years_to_double ≈ 72 / CAGR%
```

- CAGR 24% → удвоение за 3 года.
- CAGR 8% → удвоение за 9 лет.

### Правило 115
```
Years_to_triple ≈ 115 / CAGR%
```
