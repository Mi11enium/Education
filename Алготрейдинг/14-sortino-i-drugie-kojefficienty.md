# Урок 14. Sortino, Calmar, MAR и другие risk-adjusted коэффициенты

## 1. Sortino Ratio

### Отличие от Sharpe
Использует **только downside volatility** (волатильность убытков), не общую.

### Формула
```
Sortino = (E[R] - Rf) / σ_downside
```

где:
```
σ_downside = sqrt(mean(min(R - MAR, 0)²))
```

или:
```
σ_downside = std(R where R < MAR)
```

### Преимущества
- ✅ Лучше для асимметричных распределений.
- ✅ Не штрафует «хорошую» волатильность.
- ✅ Лучше отражает реальный риск.

### Пример
- Mean return: 0.1% дневно.
- MAR: 0.
- Downside σ: 0.8%.
- Sortino = 0.1 / 0.8 = **0.125** (дневной).
- Annualized = 0.125 × sqrt(252) = **1.98**.

## 2. Calmar Ratio

### Формула
```
Calmar = CAGR / |MaxDD|
```

### Пример
- CAGR: 25%.
- MaxDD: -15%.
- Calmar = 25 / 15 = **1.67**.

### Интерпретация
- < 0.5: плохо.
- 0.5–1.0: средне.
- 1.0–3.0: хорошо.
- > 3.0: отлично (или переобучение).

### Преимущества
- ✅ Простой, интуитивный.
- ✅ Учитывает худший сценарий.

## 3. MAR Ratio
То же, что Calmar, но часто за период (например, 36 месяцев).

## 4. Sterling Ratio

### Формула
```
Sterling = CAGR / Avg_Annual_DD
```

Avg DD — средняя годовая просадка (не максимальная).
- Более гладкая оценка.

## 5. Burke Ratio

### Формула
```
Burke = CAGR / sqrt(sum(DD_i²))
```

- Учитывает частоту и глубину просадок.

## 6. Information Ratio

### Формула
```
IR = (R_strategy - R_benchmark) / TE
```

- TE — tracking error = std(R_strategy - R_benchmark).
- Мера **активного** управления.

## 7. Treynor Ratio

### Формула
```
Treynor = (E[R] - Rf) / β
```

- Доходность на единицу **систематического** риска.

## 8. Omega Ratio

### Идея
Отношение upside к downside по всему распределению, а не только по σ.

```
Omega(L) = ∫[L,∞] (1-F(x))dx / ∫[-∞,L] F(x)dx
```

где L — порог (обычно 0).

### Преимущества
- ✅ Учитывает всё распределение.
- ✅ Не зависит от предположений.

## 9. Kappa 3 (ω³)
Аналогично Omega, но учитывает асимметрию и эксцесс.

## 10. Tail Ratio

```
Tail = abs(quantile(returns, 0.95)) / abs(quantile(returns, 0.05))
```

- >1: правый хвост длиннее (хорошо).
- <1: левый хвост длиннее (плохо).

## Какой коэффициент когда использовать

| Задача | Лучший |
|---|---|
| Общая оценка | Sharpe, Sortino |
| Сравнение стратегий | Sharpe, Calmar, Omega |
| С учётом MaxDD | Calmar, MAR, Sterling |
| Асимметричные returns | Sortino, Omega |
| Относительно рынка | Information, Treynor |
| Полное распределение | Omega, Kappa |

## Практические рекомендации

### Минимум метрик
Хороший дашборд стратегии:
1. **Sharpe Annual** — общая risk-adjusted.
2. **Sortino Annual** — downside-фокус.
3. **Calmar** — просадка.
4. **MaxDD** — абсолютная просадка.
5. **CAGR** — годовая доходность.

### Красные флаги
- Sharpe > 3, Calmar > 5 → проверьте переобучение.
- MaxDD > 30% → пересмотрите sizing.
- Sortino << Sharpe → много «плохой» волатильности.
