# Урок 8. Распределения и статистические тесты

## Зачем знать статистику
- Проверить, что edge **реально существует**, а не случайность.
- Сравнить стратегии.
- Оценить риски.

## Нормальное распределение

```
X ~ N(μ, σ²)
P(X ≤ x) = Φ((x - μ) / σ)
```

### Правило 68-95-99.7
- ±1σ — 68% наблюдений.
- ±2σ — 95%.
- ±3σ — 99.7%.

⚠️ В финансах «3σ события» случаются **чаще**, чем 0.3% — толстые хвосты.

## t-распределение Стьюдента

```
X ~ t(ν)
```

- ν — степени свободы (меньше = толще хвосты).
- При ν → ∞ сходится к нормальному.
- ν = 3–5 хорошо описывает PnL.

## Skewness (асимметрия)

```
Skew = E[(X - μ)³] / σ³
```

- Skew > 0: правый хвост длиннее (большие прибыли).
- Skew < 0: левый хвост длиннее (большие убытки).
- В трейдинге часто **отрицательная** (асимметрия убытков).

## Kurtosis (эксцесс)

```
Kurt = E[(X - μ)⁴] / σ⁴
```

- Нормальное: Kurt = 3.
- Финансовые: Kurt = 5–50 (толстые хвосты).
- **Excess kurtosis** = Kurt - 3.

## VaR (Value at Risk)

### Определение
Максимальный убыток с вероятностью (1 - α).
- VaR 99% = 1% квантиль.
- VaR 95% = 5% квантиль.

### Пример
- σ дневной PnL = $500.
- VaR 95% ≈ 1.65 × $500 = $825.
- VaR 99% ≈ 2.33 × $500 = $1165.

⚠️ Для толстых хвостов VaR **недооценивает** реальные убытки. Лучше CVaR.

## CVaR (Conditional VaR / Expected Shortfall)

```
CVaR_α = E[X | X ≤ -VaR_α]
```

Средний убыток **в худших** (1-α)% случаев.
✅ Лучше отражает хвостовой риск.

## Статистические тесты

### t-тест (среднее)

Проверяет H0: μ = 0 vs. H1: μ ≠ 0.

```python
from scipy import stats
t_stat, p_value = stats.ttest_1samp(pnl, 0)
```

- p_value < 0.05 → отвергаем H0 → edge статистически значим.

### Проблема
- **Независимость наблюдений** — часто нарушена.
- **Нормальность** — не выполняется.

### Альтернативы
- **Wilcoxon signed-rank test** — непараметрический.
- **Bootstrap** — бутстрап по среднему.
- **t-тест с поправкой HAC** (Newey-West) — для автокорреляции.

## Bootstrap

### Идея
Повторная выборка N с возвращением → распределение статистики.

```python
import numpy as np
means = [np.mean(np.random.choice(pnl, size=N, replace=True)) for _ in range(10000)]
ci_low, ci_high = np.percentile(means, [2.5, 97.5])
```

### Преимущества
- Не требует предположений о распределении.
- Гибкий.
- ✅ Лучший выбор для оценки доверительных интервалов PnL.

## Sharpe Ratio (вводная)
```
Sharpe = (E[R] - Rf) / σ_R
```

## Множественные тесты
Если вы тестируете 1000 стратегий, ожидайте 50 «значимых» при p<0.05 случайно.

**Решения:**
- **Bonferroni**: α / N.
- **FDR (False Discovery Rate)**: Benjamini-Hochberg.
- **Out-of-sample**: обязательно.
