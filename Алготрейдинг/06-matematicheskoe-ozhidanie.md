# Урок 6. Математическое ожидание (Edge)

## Что это
**Математическое ожидание (expected value, EV, edge)** — это **средний результат** одной сделки/ставки, если бы вы повторили её бесконечное число раз.

Edge — **единственный источник прибыли** в долгосрочной перспективе.

## Формула

### Дискретный случай (фиксированный TP/SL)

```
EV = (P_win × Avg_Win) - (P_loss × Avg_Loss)
```

где:
- `P_win` — вероятность прибыльной сделки.
- `P_loss` = 1 - P_win — вероятность убыточной.
- `Avg_Win` — средняя прибыль в выигрышной сделке.
- `Avg_Loss` — средний убыток в убыточной (обычно положительная величина).

### Пример
Стратегия: TP=200, SL=100, win rate 45%.
- EV = 0.45 × 200 - 0.55 × 100 = 90 - 55 = **35$ на сделку**.
- ✅ Положительный edge.

### Пример с комиссией
Если комиссия = 5$ на вход + 5$ на выход = 10$ на сделку.
- EV = 35 - 10 = **25$ на сделку**.

### Непрерывный случай (распределение PnL)

```
EV = E[PnL] = mean(PnL_всех сделок)
```

Считается как среднее арифметическое PnL.

## Почему edge — это главное

### Закон больших чисел
При достаточно большом N среднее сходится к мат. ожиданию:

```
PnL_total ≈ N × EV
```

При N=1000 и EV=25$ ожидаемая прибыль ≈ 25 000$.

### Время — друг, волатильность — враг
Edge реализуется **медленно**. Несколько убыточных сделок подряд — нормальное явление.

## Минимальный EV для разных стратегий

| Тип | Минимальный EV (на сделку) |
|---|---|
| Скальпинг (фьючерсы) | 0.05–0.2 тика |
| Интрадей | 0.5–2 тика |
| Свинг | 1–5% |
| Позиционная | 5%+ |

⚠️ **Главное правило**: EV > комиссии + проскальзывание.

## Откуда берётся edge

### 1. Информационное преимущество
- Вы знаете что-то раньше других.
- Законно: нет. ❌ (инсайд)

### 2. Структурное преимущество
- Спред, неэффективность, диспропорции.
- Например: «индекс торгуется выше фундаментальной стоимости».

### 3. Поведенческое преимущество
- Толпа реагирует предсказуемо.
- Покупка паники, продажа эйфории.

### 4. Техническое преимущество
- Скорость исполнения.
- Сложные типы ордеров.

### 5. Риск-преимущество
- Вы готовы к риску, который другие не хотят нести.
- Например, продажа опционов «без покрытия».

## Как измерить реальный edge

### В бэктесте
- EV = mean(PnL на сделку) в бэктесте.
- ⚠️ С учётом комиссий и проскальзывания.

### В реальной торговле
- EV = mean(реальный PnL) за N сделок.
- Тест на значимость: см. урок 12.

### Доверительный интервал
EV_sample ± 1.96 × SE, где SE = std / sqrt(N).
- Чем шире интервал — тем больше сделок нужно для уверенности.

## Проблема выживания
Стратегия с edge > 0 может показывать убытки на 100, 500 сделках. Нужна **психологическая устойчивость** и **достаточный капитал**, чтобы пережить просадку.

## Формула Келли (вводная)
Размер ставки, максимизирующий долгосрочный рост:

```
f* = (P × b - q) / b
```
- P = win rate, q = 1 - P, b = win/loss ratio.
