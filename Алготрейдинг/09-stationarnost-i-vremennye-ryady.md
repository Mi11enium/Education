# Урок 9. Стационарность и временные ряды

## Что такое стационарный ряд

**Строгая стационарность**: распределение не меняется со временем.
**Слабая стационарность**: const mean, const variance, const autocovariance.

### Почему важно
- Большинство статистических тестов предполагают стационарность.
- Неликвидные рынки / переходные режимы — нестационарны.

## Типы временных рядов

### 1. Случайное блуждание (Random Walk)
```
P_t = P_{t-1} + ε_t, ε_t ~ N(0, σ²)
```
- ❌ Не стационарный (только приращения).
- Цены активов часто близки к random walk.
- **Следствие**: нельзя предсказать будущую цену.

### 2. Mean Reverting (Ornstein-Uhlenbeck)
```
dX = κ(μ - X)dt + σ dW
```
- ✅ Стационарный.
- Спреды пар, ratio, deviation от MA.
- Примеры: парный трейдинг, Bollinger Bands.

### 3. Trending (с детерминированным трендом)
```
P_t = α + βt + ε_t
```
- ❌ Не стационарный.
- Трендследящие стратегии пытаются это эксплуатировать.

## Тесты на стационарность

### 1. ADF (Augmented Dickey-Fuller)
H0: ряд имеет unit root (нестационарный).

```python
from statsmodels.tsa.stattools import adfuller
result = adfuller(prices)
print(f'p-value: {result[1]}')
```

- p_value < 0.05 → отвергаем H0 → стационарный.

### 2. KPSS
- H0: ряд стационарный (противоположно ADF).
- Часто используют вместе: ADF+KPSS.

### 3. Hurst Exponent
- H = 0.5: random walk.
- H < 0.5: mean-reverting.
- H > 0.5: trending.

```python
from hurst import compute_Hc
H, c, data = compute_Hc(prices)
```

## Спреды и pair trading

### Если два актива коинтегрированы
- Спред = P_A - β × P_B стационарен.
- Можно торговать отклонения.

### Тест на коинтеграцию: Engle-Granger

```python
from statsmodels.tsa.stattools import coint
score, pvalue, _ = coint(price_a, price_b)
```

- p_value < 0.05 → коинтегрированы.

### Johansen test (для нескольких активов)
Лучше для портфеля из 3+ активов.

## Что делать с нестационарностью

### 1. Работать с приращениями
```
returns = prices.pct_change()
```
✅ Стационарны (в большинстве случаев).

### 2. Детренд
- Вычесть MA.
- Взять deviation от MA.

### 3. Логарифмы
```
log(P) = ln(P)
```
- Лучше для процентных изменений.
- Нормализует дисперсию.

### 4. Использовать спреды
- Спред двух коинтегрированных активов.

## Структурные сдвиги (Structural Breaks)

### Тесты
- **Chow test**.
- **CUSUM test**.
- **Bai-Perron** (множественные сдвиги).

### Почему важно
- Изменение режима: кризис 2008, COVID 2020.
- Стратегия, работавшая 5 лет, может сломаться.

### Как детектить
- Мониторинг Sharpe.
- CUSUM на equity.
- Тест на изменение среднего (Chow, Pettitt).

## Практические выводы

### 1. Цены нестационарны — работайте с returns
- Mean/std/spread — стационарны в большинстве случаев.

### 2. Спреды коинтегрированных пар — стационарны
- Используйте для mean reversion.

### 3. Мониторьте структурные сдвиги
- Пересчитывайте параметры скользящего окна.

### 4. Не доверяйте «вечным» стратегиям
- Всё меняется, режимы — тоже.
