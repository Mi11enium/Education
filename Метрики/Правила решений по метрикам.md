# Правила решений по метрикам

Краткие эвристики для Canvas (можно связать с [[ACOS]], [[ROAS]], [[CR в заказ]], [[Выкуп]], [[Unit-экономика]]).

## Реклама

- **Высокий CR + хороший выкуп + хороший ROAS (низкий ACOS)** → можно увеличивать бюджет
- **Низкий CR при любом ACOS** → сначала контент карточки, не бюджет
- **ACOS стабильно выше маржи по unit-экономике** → урезать или отключить
- **GMV растёт, выкуп падает** → не масштабировать рекламу, пока не разберёте невыкуп

## Приоритет правок карточек

1. Высокие [[Показы]] / расход рекламы + плохой [[CTR]] или [[CR в заказ]] → максимальный эффект
2. Низкий [[Выкуп]] при нормальном CR → ожидания, цена «на ПВЗ», честность контента
3. Растущий [[Процент возвратов]] / [[Возвраты]] → срочно честность контента
4. Низкий [[Рейтинг]] при трафике → отзывы и продукт
5. Плохая [[Unit-экономика]] при росте [[GMV]] → стоп масштаб, пересчёт цены/COGS/рекламы

## Контент → метрика (кратко)

- Обложка, название → [[CTR]]
- Галерея, видео, описание → [[CR в корзину]]
- Отзывы, рейтинг, цена → [[CR в заказ]]
- Честные фото, размеры, оффер → [[Выкуп]], [[Процент возвратов]]
- Наборы, кросс → [[Средний чек]], [[AOV]], [[GMV]]
- Всё вместе → [[Unit-экономика]]
