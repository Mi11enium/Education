# Правила решений по метрикам

Краткие эвристики для Canvas (можно связать с [[ACOS]], [[ROAS]], [[CR в заказ]]).

## Реклама

- **Высокий CR + хороший ROAS (низкий ACOS)** → можно увеличивать бюджет
- **Низкий CR при любом ACOS** → сначала контент карточки, не бюджет
- **ACOS стабильно выше маржи** → урезать или отключить, пока не исправите оффер/контент

## Приоритет правок карточек

1. Высокие [[Показы]] / расход рекламы + плохой [[CTR]] или [[CR в заказ]] → максимальный эффект
2. Растущий [[Процент возвратов]] → срочно честность контента
3. Низкий [[Рейтинг]] при трафике → отзывы и продукт

## Контент → метрика (кратко)

- Обложка, название → [[CTR]]
- Галерея, видео, описание → [[CR в корзину]]
- Отзывы, рейтинг, цена → [[CR в заказ]]
- Честные фото и размеры → [[Процент возвратов]]
