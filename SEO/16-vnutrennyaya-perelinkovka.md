# Урок 16. Внутренняя перелинковка

## Что это
**Внутренняя перелинковка** — это ссылки между страницами одного сайта. Это один из самых мощных on-page инструментов.

## Зачем нужна

### 1. Распределение PageRank
Google использует внутренние ссылки для распределения «веса» (PageRank) между страницами.
- Ссылка с главной → больше веса получает целевая страница.

### 2. Ускорение индексации
Краулер переходит по ним → быстрее находит и индексирует страницы.

### 3. Улучшение UX
Пользователь легко перемещается по сайту → больше страниц за сессию → поведенческие факторы.

### 4. Якорная семантика
Анкор ссылки сообщает ПС, о чём целевая страница.

## Типы внутренних ссылок

| Тип | Где | Пример |
|---|---|---|
| Навигационные | Меню, футер | «О нас», «Каталог» |
| Контекстные | В тексте статьи | «подробнее о iPhone 15» |
| Блочные | Блоки «Похожие товары» | Карточки товаров |
| Хлебные крошки | Под заголовком | Главная → Каталог → Товар |
| Ссылки в сайдбаре | Боковая колонка | Популярные статьи |

## Анкоры (anchor text)

### Что такое анкор
Это кликабельный текст ссылки.

`<a href="/iphone-15">обзор iPhone 15</a>`
                     └──── анкор ────┘

### Типы анкоров
- **Точное вхождение** — `iPhone 15` (рискованно).
- **Разбавленное** — `обзор iPhone 15`, `смартфон Apple iPhone 15`.
- **LSI/синоним** — `смартфон Apple нового поколения`.
- **Брендовый** — `Apple`, `название бренда`.
- **Безанкорный** — `здесь`, `читать далее`, `ссылка`.
- **URL-анкор** — `example.com/page`.

### Распределение анкоров (правило «здорового» профиля)
- 30–40% — разбавленные/LSI.
- 20–30% — безанкорные.
- 10–15% — точные вхождения.
- 10–15% — брендовые.

❌ Не спамьте точными вхождениями → Google считает манипуляцией.

## Стратегии перелинковки

### «Силос» (silo)
Тематическая группировка страниц, где все ссылки внутри силоса ведут только друг на друга.
```
  [Статья 1]
   ↓ ↑  ↘
[Статья 2] → [Статья 3]
              ↓
         [Карточка товара]
```

### Хабы (hub-spoke)
Главная страница-хаб ссылается на все статьи темы, и они ссылаются обратно на хаб.
```
        [Хаб: SEO]
       /    |    \
  [Статья1][Статья2][Статья3]
```

## Практические правила

1. **Не больше 100–150 ссылок** на страницу (рекомендация Google).
2. **Одна ссылка на URL** в пределах одной страницы (обычно).
3. **Контекстные ссылки** > навигационных для SEO.
4. **Старые статьи** ссылаются на новые и наоборот.
5. **Битые ссылки** (404) срочно исправлять.

## Инструменты
- **Screaming Frog** — парсинг всех внутренних ссылок.
- **Ahrefs Site Audit** — орфанные страницы (без ссылок).
- **Google Search Console** — «Внутренние ссылки» (статистика).

## Чек-лист урока
- [ ] На каждой странице есть 3–10 внутренних ссылок.
- [ ] Анкоры разнообразные и описательные.
- [ ] Новые статьи получают ссылки со старых.
- [ ] Нет битых ссылок.
- [ ] Структура напоминает хаб или силос.
