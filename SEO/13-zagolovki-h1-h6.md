# Урок 13. Заголовки H1–H6

## Иерархия заголовков

```html
<h1>Главный заголовок страницы</h1>
  <h2>Раздел 1</h2>
    <h3>Подраздел 1.1</h3>
    <h3>Подраздел 1.2</h3>
  <h2>Раздел 2</h2>
    <h3>Подраздел 2.1</h3>
      <h4>Детализация</h4>
```

## H1 — главный заголовок

### Требования
- **Один H1 на странице** (рекомендация Google).
- Содержит целевой ключ.
- Не должен быть идентичен Title (но близок).
- Видимый пользователю.

### Примеры хороших H1
- `Обзор iPhone 15: характеристики, цена, сравнение`
- `Купить ноутбук для работы`
- `Услуги веб-разработки в Москве`

### Анти-паттерны
- ❌ Несколько H1 на одной странице.
- ❌ Пустой H1.
- ❌ H1 = «Главная» / «Home».
- ❌ H1 без ключа (для информационных страниц).

## H2–H6 — структура

### H2 — разделы
- Используются для основных блоков контента.
- Должны быть 3–7 H2 на среднюю статью.
- Содержат под-ключи или LSI-слова.

### H3 — подразделы
- Детализация внутри H2.
- Используются для под-вопросов, шагов инструкции, вариантов.

### H4–H6 — мелкие подразделы
- Используются редко (длинные технические статьи, документация).

## Правила иерархии
✅ Не пропускайте уровни (h2 → h4 нельзя).
✅ H2 ≈ тезис раздела, H3 ≈ факты внутри.
✅ Каждый H2/H3 — законченный фрагмент смысла.
✅ Используйте ключевые слова естественно.

## Пере- или недо-использование

### Плохо: одна «простыня»
```
<h1>Статья</h1>
<p>Lorem ipsum...</p>
```

### Хорошо: структура
```
<h1>Как выбрать ноутбук</h1>
  <h2>По назначению</h2>
  <h2>По характеристикам</h2>
    <h3>Процессор</h3>
    <h3>Оперативная память</h3>
  <h2>Топ-5 моделей</h2>
```

## Влияние на SEO
- Заголовки помогают ПС понять структуру и темы страницы.
- Используются для **Featured Snippets** (Google берёт ответ из H2/H3 + абзац).
- Улучшают UX — пользователь сканирует текст глазами.

## Heading vs. Title
| Title | H1 |
|---|---|
| Заголовок в браузере/выдаче | Заголовок на странице |
| Может отличаться от H1 | Основной заголовок контента |
| Часто кликбейтный | Должен быть честным |

## Чек-лист урока
- [ ] Один H1 на странице.
- [ ] Иерархия без пропусков.
- [ ] 3–7 H2 для средней статьи.
- [ ] Ключи в H1/H2 естественно.
