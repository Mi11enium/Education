# Урок 28. Сайт-силосы и pillar pages

## Концепция
**Силос** — это тематическая группировка страниц, где все ссылки идут только внутри «колонца» темы.

**Pillar page** (хаб-страница) — главная страница силоса, которая ссылается на все подстраницы и обратно.

## Преимущества
✅ Концентрация PageRank внутри темы.
✅ ПС понимает тематическую экспертизу сайта.
✅ Лучшее ранжирование по всем ключам кластера.
✅ Удобная навигация для пользователя.

## Структура силоса

```
              [PILLAR: Как выбрать ноутбук]
                  /            |            \
                 ↓             ↓             ↓
     [Подбор по бюджету] [Игровые] [Для работы]
              ↓              ↓           ↓
           [Под-          [Топ-5     [Топ-5
            темы...]        игровых]  рабочих]
```

### Принципы
1. Все ссылки внутри силоса — только внутри.
2. Pillar ссылается на все под-страницы.
3. Под-страницы ссылаются на pillar и друг на друга (контекстно).
4. Силосы не пересекаются (или пересекаются минимально).

## Создание pillar page

### Какая страница — pillar
- Широкая тема с большим поисковым спросом.
- Много LSI-ключей вокруг.
- Вы хотите стать авторитетом в теме.

### Структура pillar
1. **Intro** — что это, кому полезно.
2. **Оглавление** с якорями.
3. **Подразделы** (H2) — каждый раскрывает один аспект.
4. **Ссылки на cluster articles** — в каждом подразделе.
5. **Заключение + CTA**.

### Длина pillar
- 3000–10000 слов (длинный гайд).

## Cluster articles (под-страницы)
- Узкие темы, детализирующие подраздел pillar.
- 800–2500 слов.
- Имеют свой целевой ключ.
- Обязательно ссылаются на pillar + смежные cluster.

## Пример: SEO силос

```
[Pillar: Полный гид по SEO]
   ├── [On-page SEO: 20 советов]
   │     ├── [Title tag: правила]
   │     ├── [Meta description]
   │     └── [Alt-теги изображений]
   ├── [Technical SEO: чек-лист]
   │     ├── [robots.txt]
   │     └── [Core Web Vitals]
   ├── [Link building]
   └── [Локальное SEO]
```

## Как внедрять

### Шаг 1. Тематический анализ
Определите основные тематики вашего сайта.

### Шаг 2. Создание pillar
Для каждой тематики — главная страница-хаб.

### Шаг 3. Связывание
- Pillar → все cluster.
- Cluster → pillar.
- Cluster ↔ cluster (контекстно).

### Шаг 4. Мониторинг
- Позиции pillar и cluster.
- PageRank flow (через визуализацию ссылок).

## Альтернатива: тематический авторитет
Не обязательно строить жёсткие силосы. Достаточно:
- Чёткая тематическая структура.
- Логичная навигация.
- Связи между тематическими страницами.

## Чек-лист урока
- [ ] Сайт имеет чёткую тематическую структуру.
- [ ] Для каждой большой темы — pillar page.
- [ ] Cluster articles ссылаются на pillar и друг на друга.
- [ ] Ссылки между силосами — только при необходимости.
- [ ] Нет «висячих» страниц без ссылок.
