# Урок 24. Mobile SEO

## Важность mobile
- **Mobile-first indexing** — Google индексирует мобильную версию (с 2018, полностью с 2021).
- **70%+** трафика — мобильный.
- **Mobile-friendly** — фактор ранжирования.

## Три подхода к мобильной версии

### 1. Responsive Design
Один URL, макет подстраивается под размер экрана.
```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```
✅ **Рекомендуется Google.**
✅ Один URL, один контент.
✅ Проще поддерживать.

### 2. Dynamic Serving
Один URL, разный HTML для разных устройств.
HTTP-заголовок `Vary: User-Agent`.
✅ Хорошо для SEO (один URL).
⚠️ Сложнее дебажить.

### 3. Separate Mobile Site
`m.example.com` — отдельная версия.
❌ Много проблем (дубли, редиректы).
❌ Google рекомендует уходить с этого подхода.

## Mobile-friendly чек-лист

### Технические
- ✅ Viewport meta-тег.
- ✅ Адаптивная вёрстка (responsive).
- ✅ Одинаковый контент mobile и desktop.
- ✅ Структурированные данные одинаковые.
- ✅ Meta-теги одинаковые.
- ✅ robots.txt, sitemap — одинаковые.

### UX
- ✅ Текст читаемый без зума (16px+ базовый).
- ✅ Кнопки / ссылки тапабельные (44×44 px минимум).
- ✅ Нет горизонтального скролла.
- ✅ Нет Flash, нет intrusive popups.
- ✅ Расстояние между интерактивными элементами.

### Скорость
- ✅ Mobile PageSpeed > 50 (хорошо).
- ✅ LCP < 2.5 сек.
- ✅ Изображения адаптивные.

## Intrusive Interstitials
Google штрафует за навязчивые межстраничные баннеры на мобильных:

❌ Плохо:
- Полноэкранный popup до контента.
- Модальное окно, которое сложно закрыть.
- Layout-shifting баннер сверху.

✅ Допустимо:
- Cookie-баннеры (по закону).
- Баннеры с возрастным ограничением.
- Логичные диалоги (вход в аккаунт).

## AMP (Accelerated Mobile Pages)
HTML-фреймворк для сверхбыстрых мобильных страниц.

### Когда имеет смысл
- Новостные сайты.
- Большой объём мобильного трафика.
- Готовы поддерживать отдельную версию.

### Когда не стоит
- Сложный интерактивный контент.
- E-commerce (сложно поддерживать).
- Google уже **не даёт преимуществ** в выдаче с 2021.

## Mobile Usability отчёт
**GSC → Опыт использования → Удобство для мобильных** — список проблем:
- Слишком мелкий шрифт.
- Интерактивные элементы слишком близко.
- Контент шире экрана.
- Не задана viewport.

- [ ] Responsive design (не отдельный m. сайт).
- [ ] Viewport meta-тег.

- [ ] Тапабельные элементы ≥ 44 px.
- [ ] Mobile PageSpeed > 50.
- [ ] Mobile-friendly тест Google — passed.
