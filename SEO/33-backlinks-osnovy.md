# Урок 33. Бэклинки: основы Off-Page SEO

## Что такое бэклинк
**Бэклинк (backlink)** — это входящая ссылка с другого сайта на ваш. Один из важнейших факторов ранжирования.

```
Сайт A (донор) ──── ссылка ────→ Сайт B (акцептор)
                ↑
            backlink для B
```

## Почему бэклинки важны
1. **Голос доверия** — другая площадка «рекомендует» вас.
2. **PageRank** — передаётся через ссылки (но не всё).
3. **Discoverability** — краулер находит вас по ссылкам.
4. **Реферальный трафик** — реальные пользователи.

## Характеристики «хорошего» бэклинка

### 1. Качество донора
- **DR/DR (Domain Rating)** — Ahrefs: чем выше, тем авторитетнее.
- **DA** — Moz.
- **ИКС** — Яндекс.
- **Trust Flow** — Majestic.
- **Спамность** — спамные сайты дают токсичные ссылки.

### 2. Тематичность
- ✅ Ссылка с похожего по теме сайта весит больше.
- ❌ Ссылка с сайта другой тематики (менее релевантна).

### 3. Тип ссылки
- **Dofollow** — передаёт PageRank.
- **Nofollow** — не передаёт, но даёт разнообразие.
- **Sponsored** — для рекламных.
- **UGC** — для пользовательского контента.

⚠️ Google анонсировал «анонимизацию» атрибутов — переход к анализу «по сути», а не по атрибутам. Поэтому nofollow тоже ценен.

### 4. Расположение
- ✅ Внутри контента (контекстная).
- ⚠️ В сайдбаре/футере (менее ценно).
- ❌ В скрытом блоке.

### 5. Анкор
- Анкор с ключом — мощный сигнал.
- Брендовый анкор — естественный.
- URL-анкор — нейтральный.

## Где берут бэклинки

### Естественные
- PR, упоминания в СМИ.
- Каталоги и справочники.
- Форумы, сообщества.
- Комментарии (если полезные).
- Партнёрские материалы.

### Искусственные
- Гостевые посты.
- PBN (Private Blog Network).
- Купленные ссылки.
- Обмен ссылками.
- Крауд-маркетинг.

## Естественный профиль ссылок
У здорового сайта профиль разнообразный:

| Тип анкора | % |
|---|---|
| Брендовый | 30–50% |
| URL | 15–25% |
| Безанкорный («здесь», «подробнее») | 15–25% |
| Точный ключ | 5–15% |
| Разбавленный ключ | 10–20% |

## Доноры: на что смотреть
- ✅ Тематика близка к вашей.
- ✅ Высокий DR/DA.
- ✅ Реальный трафик (не «пустышка»).
- ✅ Сайт индексируется.
- ✅ Нет признаков спама.
- ✅ Контент уникальный.
- ❌ Избегайте: дорвеев, сайтов под фильтром, спам-каталогов.

## Как проверить бэклинки
- **Ahrefs Site Explorer**, **SEMrush**, **Majestic** — все ссылки.
- **Google Search Console → Ссылки** — топ доменов.
- **Яндекс.Вебмастер → Внешние ссылки**.

## Яндекс про бэклинки
Яндекс официально не учитывает nofollow.
**Минусинск** — фильтр за покупные ссылки (с 2015).
Естественный профиль — залог успеха.
