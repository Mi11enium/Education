# Урок 12. Meta Description: описание страницы

## Что такое Meta Description
**Meta Description** — тег `<meta name="description">`. Используется как сниппет в результатах поиска.

`<meta name="description" content="Узнайте, как выбрать ноутбук для работы: топ-10 моделей 2025 года, сравнение характеристик и цен.">`

## Важно знать
- Google **не использует** Description как фактор ранжирования напрямую.
- Но Description **влияет на CTR** → больше кликов → поведенческие сигналы → косвенно рост позиций.
- Google может переписать Description, если сочтёт, что другой фрагмент страницы лучше отвечает на запрос.

## Правила

### Длина
- **120–160 символов** (включая пробелы).
- До ~920 px — без обрезки.
- На мобильных — меньше символов.

### Структура формулы
`[Действие/обещание] + [выгода] + [призыв к действию] + [ключ]`

Примеры:
- `Узнайте 7 проверенных способов увеличить продажи в интернет-магазине. Практические советы от экспертов. Читайте в нашем блоге!`
- `Купите iPhone 15 в нашем магазине: доставка по Москве за 1 день, гарантия 2 года, рассрочка 0%. Закажите сейчас!`

### Требования
- ✅ Один уникальный Description на странице.
- ✅ Целевой ключ (Google выделяет его жирным).
- ✅ Call-to-action (CTA): «читайте», «закажите», «узнайте».
- ✅ Конкретика: числа, факты, цены.
- ✅ До 160 символов.

### Анти-паттерны
- ❌ Одинаковый Description на всех страницах (шаблонный).
- ❌ «Главная» / «Добро пожаловать».
- ❌ Спам ключами.
- ❌ Полная копия первого абзаца.

## Где Description не работает
- Яндекс часто игнорирует Description, формируя свой сниппет из текста.
- На некоторых CMS Description автоматически генерируется из excerpt.

## Description для разных типов страниц

### Главная
`Компания X — лидер в [ниша]. [Что делаем], [гео], [опыт]. Узнайте больше на сайте!`

### Категория
`[Товаров/услуг N] в категории. Цены от X ₽. Доставка по [гео]. Скидка при заказе онлайн!`

### Карточка товара
`[Товар] по цене X ₽. Купить с доставкой по [гео] за 1 день. Гарантия 2 года. Отзывы покупателей.`

### Статья
`Узнайте, как [тема]. В статье — пошаговая инструкция, примеры и советы эксперта. Время чтения — N мин.`

## Как проверять
- В поиске по запросу site:yoursite.com.
- Через расширения: SEOquake, MozBar.
- Screaming Frog — массовая проверка.

## Чек-лист урока
- [ ] Description 120–160 символов.
- [ ] Целевой ключ + CTA.
- [ ] Уникальный для каждой страницы.
- [ ] Конкретика (числа, факты, цены).
