# Урок 25. HTTPS и безопасность сайта

## Что такое HTTPS
**HTTPS** — HTTP + TLS/SSL. Шифрует трафик между браузером и сервером.

`http://example.com` — нешифрованный.
`https://example.com` — шифрованный.

## Почему HTTPS важен для SEO

1. **Фактор ранжирования** (с 2014 года).
2. **Без HTTPS — предупреждение** в Chrome «Не защищено».
3. **Referer сохраняется** — с HTTP на HTTPS реферер обрезается → GA теряет источники.
4. **HTTP/2, HTTP/3** — обычно только с HTTPS.
5. **Требование для PWA, Service Workers, Geo API** и других современных фич.

## Как перейти на HTTPS

### Шаг 1. SSL-сертификат
- **Let's Encrypt** — бесплатный, автоматический, 90 дней.
- **Cloudflare** — бесплатный через прокси.
- **Коммерческие** (Comodo, DigiCert) — для бизнеса с расширенной проверкой (EV).
- **Wildcard** — для поддоменов.

### Шаг 2. Установка
Зависит от хостинга (cPanel, ISPmanager, nginx + certbot).

### Шаг 3. Настройка
1. **301-редирект** с HTTP на HTTPS (со всех страниц).
2. **Canonical** на HTTPS-версию.
3. **Sitemap** — только HTTPS URL.
4. **Внутренние ссылки** — относительные (`//`) или HTTPS.
5. **robots.txt** — укажите HTTPS-версию sitemap.

### Шаг 4. Обновите внешние сигналы
- Google Search Console — добавьте HTTPS-версию.
- Яндекс.Вебмастер — перенастройте.
- Google Analytics / GA4 — обновите URL.
- Соцсети, каталоги, профили — везде поменяйте URL.

## HSTS (HTTP Strict Transport Security)
Заголовок, который говорит браузеру всегда использовать HTTPS:

```
Strict-Transport-Security: max-age=31536000; includeSubDomains; preload
```

✅ Включайте после полного перехода на HTTPS.

## Mixed Content
Когда HTTPS-страница загружает HTTP-ресурсы (картинки, скрипты).
❌ Блокируется браузерами.
✅ Проверьте: DevTools → Console → Mixed Content warnings.

## Сертификаты и SEO
- Истёкший сертификат — пользователи видят предупреждение.
- Мониторьте дату истечения.
- Self-signed сертификаты — только для тестирования.

## Безопасность для SEO

### 3 главные угрозы
1. **Взлом сайта** (defacement) → падение доверия → ручные санкции.
2. **Инъекция спам-ссылок** → продажа ссылок без вашего ведома.
3. **Фарминг ссылок** через вирусы на хостинге.

### Защита
- ✅ Регулярные обновления CMS, плагинов, серверного ПО.
- ✅ Сложные пароли, 2FA.
- ✅ WAF (Web Application Firewall) — Cloudflare, Sucuri.
- ✅ Регулярный бэкап.
- ✅ Мониторинг изменений файлов.
- ✅ Аудит исходящих ссылок.
