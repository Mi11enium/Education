# Урок 50. Итоговый SEO-чеклист контент-менеджера

## 🎯 Главный чек-лист для ежедневной работы

### A. Перед публикацией любой страницы

#### Мета-теги
- [ ] Title — 50–65 символов, ключ ближе к началу, уникальный.
- [ ] Description — 120–160 символов, ключ + CTA, уникальный.
- [ ] H1 — один на странице, с ключом, отличается от Title (или совпадает, если уместно).

#### Структура
- [ ] Иерархия H2–H6 без пропусков.
- [ ] URL — короткий, читаемый, с ключом.
- [ ] Хлебные крошки (если есть).

#### Контент
- [ ] Минимум 300+ слов уникального текста.
- [ ] Целевой ключ в первом абзаце и в одном H2.
- [ ] LSI-слова использованы естественно.
- [ ] Нет переспама (плотность <5%).
- [ ] Текст раскрывает интент полностью.
- [ ] Списки, таблицы, цитаты — где уместно.

#### Мультимедиа
- [ ] Изображения сжаты (WebP), до 200 KB.
- [ ] Alt-теги осмысленные.
- [ ] Lazy loading для картинок ниже первого экрана.
- [ ] Видео (если есть).

#### Schema
- [ ] Соответствующий тип (Article, Product, FAQPage).
- [ ] Валидируется в Schema.org.
- [ ] Видимый контент соответствует разметке.

#### Техника
- [ ] Canonical на правильный URL.
- [ ] Не закрыта в robots.txt.
- [ ] HTTPS.
- [ ] PageSpeed > 70 mobile.

#### Внутренняя перелинковка
- [ ] 3+ внутренних ссылки на страницу.
- [ ] Анкоры описательные и разнообразные.
- [ ] Связь с подходящими силосами/хабами.

### B. После публикации

- [ ] Добавить URL в sitemap.xml.
- [ ] Проверить индексацию (GSC → URL Inspection) через 1–3 дня.
- [ ] Проверить, что страница появилась в GSC → Покрытие.
- [ ] Сделать ссылку со связанных страниц.
- [ ] Проверить, что нет 404 или soft 404.

### C. Еженедельно

- [ ] GSC → Performance — динамика позиций и CTR.
- [ ] GSC → Покрытие — новые ошибки индексирования.
- [ ] GSC → Улучшения — новые предупреждения.
- [ ] Яндекс.Вебмастер → Сводка.
- [ ] Rank tracker — динамика позиций.
- [ ] GA4 → Organic traffic.
- [ ] Мониторинг новых бэклинков.

### D. Ежемесячно

- [ ] SEO-аудит (Screaming Frog) — выборочно или полный.
- [ ] Проверка скорости (PageSpeed Insights).
- [ ] Проверка мобильной версии.
- [ ] Обновление топовых материалов.
- [ ] Удаление / переработка тонкого контента.
- [ ] Анализ конкурентов.
- [ ] Отчёт по KPI (трафик, позиции, лиды).
- [ ] Мониторинг токсичных ссылок.
- [ ] Проверка NAP (если локальный бизнес).

### E. Ежеквартально

- [ ] Полный SEO-аудит.
- [ ] Обновление семантического ядра.
- [ ] Пересмотр контент-плана.
- [ ] Анализ бэклинков конкурентов.
- [ ] Тест новых SERP-фич (Featured Snippet, AI Overviews).
- [ ] Обновление Schema-разметки.
- [ ] Пересмотр карты сайта.

### F. Главные ошибки контент-менеджера

#### Стратегические
- ❌ Публиковать без keyword research.
- ❌ Игнорировать интент.
- ❌ Копировать контент конкурентов.
- ❌ Забывать про обновление старых материалов.

#### Тактические
- ❌ Одинаковые Title/Description на всех страницах.
- ❌ Title > 70 символов.
- ❌ Несколько H1.
- ❌ Нет alt-тегов.
- ❌ Тонкий контент (<300 слов).
- ❌ Переспам ключами.
- ❌ Битые ссылки.
- ❌ Нет внутренней перелинковки.

#### Технические
- ❌ Забыть про canonical.
- ❌ Закрыть важные страницы в robots.txt.
- ❌ Дубли без решения.
- ❌ Нет sitemap.
- ❌ Сайт на HTTP.

## 🎓 Финальные рекомендации

### 1. Учитесь постоянно
- SEO меняется каждый год.
- Читайте блоги: Ahrefs, Moz, Search Engine Journal, Search Engine Roundtable.
- YouTube-каналы: Ahrefs, SEMrush, Google Search Central.
- Подписки: Search Engine Roundtable, Search Engine Land.

### 2. Думайте как пользователь
- Помогайте людям, а не машинам.
- E-E-A-T = реальная польза.
- Удобство сайта > хитрые трюки.

### 3. Думайте как редактор
- Качество важнее количества.
- Один сильный материал > 10 слабых.
- Всегда думайте: «А я бы это читал?»

### 4. Думайте как аналитик
- Метрики решают.
- Тестируйте гипотезы.
- Документируйте эксперименты.

### 5. Думайте как предприниматель
- SEO = инвестиция с отложенным результатом.
- Считайте ROI.
- Общайтесь с бизнесом на языке бизнеса.
