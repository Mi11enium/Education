# Урок 41. Google Search Console: главный инструмент SEO

## Что такое GSC
**Google Search Console** — бесплатный инструмент от Google для мониторинга сайта в поиске.

`https://search.google.com/search-console/`

## Основные отчёты

### 1. Производительность (Performance)
Главный отчёт: показывает, как сайт появляется в поиске.
- **Показы** — сколько раз показан URL.
- **Клики** — сколько раз кликнули.
- **CTR** — кликабельность.
- **Средняя позиция**.

Фильтры:
- По запросам.
- По страницам.
- По странам.
- По устройствам.
- По датам.

### 2. Покрытие (Coverage)
Статус индексации страниц:
- ✅ Проиндексировано.
- ⚠️ Не проиндексировано (с причиной).
- ⚠️ Предупреждения.
- ❌ Исключено.

Причины исключения:
- Страница с alternate canonical.
- Crawled but not indexed.
- Excluded by noindex.
- Duplicate without user-selected canonical.
- Soft 404.
- Redirect.

### 3. Карта сайта (Sitemaps)
- Загруженные sitemap.
- Статус и количество URL.
- Ошибки парсинга.

### 4. Улучшения (Enhancements)
- Mobile Usability.
- Core Web Vitals.
- Breadcrumbs.
- FAQ.
- HowTo.
- Sitelinks Searchbox.
- Logos.

### 5. Ссылки (Links)
- Внешние ссылки (топ доменов).
- Внутренние ссылки (топ страниц).
- Самые частые анкоры.

### 6. Безопасность и ручные меры
- Проблемы безопасности (взлом, malware).
- Ручные санкции (action).
- ⚠️ Если есть — решать немедленно.

### 7. URL Inspection
- Проверка конкретного URL.
- Статус индексации.
- Последний обход краулером.
- Можно запросить переиндексацию.

## Как использовать

### На регулярной основе
1. **Производительность** — раз в неделю: падает ли CTR, позиции.
2. **Покрытие** — раз в неделю: новые ошибки.
3. **Улучшения** — раз в месяц: новые warning'и.
4. **Ссылки** — раз в месяц: новые доноры.

### Для диагностики
1. URL Inspection — проверить индексацию страницы.
2. Производительность → сравнить с прошлым месяцем.
3. Покрытие → найти причины исключений.

## Частые сценарии

### «Страница не индексируется»
1. URL Inspection → проверить статус.
2. Если «Crawled but not indexed» — плохой контент, дубли.
3. Если «Excluded by noindex» — проверить мета-теги.
4. Если «Discovered but not crawled» — добавить внутренние ссылки, проверить robots.txt.

### «Позиции упали»
1. Производительность → сравнить с прошлым месяцем.
2. Проверить, не было ли апдейтов Google.
3. Сравнить с конкурентами.
4. Проверить Покрытие (не исключили ли страницу).

### «CTR просел»
1. Производительность → CTR по запросам.
2. Конкретные запросы с низким CTR → оптимизация Title/Description.

### «Мало показов»
1. Возможно, страница не индексируется (Покрытие).
2. Возможно, устарела семантика.
3. Сравнить с конкурентами по охвату.

## Настройка
1. Зарегистрировать домен (DNS-верификация рекомендуется).
2. Добавить sitemap.xml.
3. Пригласить коллег с разными ролями.
4. Связать с Google Analytics 4.

## Что НЕ показывает GSC
- ❌ Позиции по конкретным ключам с точностью (только средняя).
- ❌ Полный список бэклинков.
- ❌ Точные данные по конкурентам.
- ❌ Данные по другим поисковикам (Яндекс, Bing).
