# Урок 7. Инструменты подбора ключевых слов

## Бесплатные инструменты

### Google
- **Google Search Console** — уже ранжирующиеся запросы вашего сайта.
- **Google Trends** — тренды запросов, сравнение сезонности.
- **Google Keyword Planner** — частотность (требует Ads-аккаунт).
- **Google "Похожие запросы"** — внизу SERP.
- **Google "Люди также ищут"** — в результатах.

### Яндекс
- **Яндекс.Вебмастер** — запросы сайта.
- **Яндекс.Wordstat** — частотность.
- **Яндекс.Поиск** — подсказки и блок "Люди ищут".

### Другие
- **AnswerThePublic** — вопросы и предлоги.
- **Ubersuggest** (ограниченно бесплатно).
- **Keyword Tool** (генерация длинных хвостов).

## Метрики ключевых слов

### Частотность
- **Точная (exact)** — точное совпадение слова.
- **Широкая (broad)** — содержит слова в любом порядке.
- **Wordstat** показывает "показов в месяц" — условная метрика.

### Конкурентность (KD, Keyword Difficulty)
- Чем выше % — тем сложнее выйти в топ.
- Для нового сайта ориентируйтесь на KD < 30.

### CTR (в SERP)
- Запросы с Featured Snippet / PAA — высокий потенциал CTR.

### CPC (Cost Per Click)
- Косвенный сигнал коммерческой ценности запроса.

## Процесс подбора (workflow)

1. **Brainstorm** — список тем.
2. **Расширение** — через инструменты (LSi, похожие, PAA).
3. **Фильтрация** — по интенту, частотности, KD.
4. **Кластеризация** — группировка по страницам.
5. **Приоритизация** — по ROI и ресурсам.
6. **Маппинг** — назначение ключа → URL.

## Лайфхаки
- Используйте операторы Google: `"точная фраза"`, `site:`, `intitle:`, `inurl:`.
- Смотрите «связанные ключи» в Serpstat/Ахрефс.
- Проверяйте сезонность в Google Trends.
- Не игнорируйте вопросительные запросы (How, What, Why).
