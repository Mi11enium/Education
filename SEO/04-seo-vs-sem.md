# Урок 4. SEO vs SEM и место SEO в маркетинге

## Определения

**SEO (Search Engine Optimization)** — оптимизация сайта для органической выдачи. Бесплатный трафик, долгосрочный эффект.

**SEM (Search Engine Marketing)** — весь комплекс маркетинга в поиске: SEO + контекстная реклама (PPC) + покупка и оптимизация рекламных кампаний.

## Сравнение SEO и PPC (контекстная реклама)

| Параметр | SEO | PPC (Яндекс.Директ, Google Ads) |
|---|---|---|
| Стоимость клика | Бесплатно | Платно (аукцион) |
| Время запуска трафика | 1–6 месяцев | Часы |
| Долгосрочный эффект | Накапливается | Прекращается с отключением |
| Доверие пользователей | Высокое | Ниже (помечено «Реклама») |
| CTR в среднем | 15–30% (топ-3) | 3–10% |
| Контроль позиций | Косвенный | Прямой |
| Ограничения | Алгоритмы ПС | Бюджет |

## Когда использовать SEO
✅ Долгосрочная стратегия (от 6 месяцев).
✅ Высокая конкуренция в нише — SEO дешевле PPC на дистанции.
✅ Контентные проекты (блоги, медиа, информационные сайты).
✅ Бизнес с длинным циклом сделки (B2B, услуги).

## Когда PPC эффективнее
⚡ Сезонные акции, распродажи.
⚡ Тестирование гипотез (запрос → лендинг).
⚡ Новый продукт без органической истории.
⚡ Высокочастотные коммерческие запросы с дорогим кликом.

## Синергия SEO + PPC
1. Данные PPC → для SEO (эффективные запросы).
2. SEO-страницы → поддержка PPC качественным контентом.
3. Совместный анализ поиска → объединённая стратегия.
4. Брендовые запросы лучше держать в обоих каналах.

## Каналы в поисковом маркетинге
- **Поиск** (Google, Яндекс) — SEO + PPC.
- **Карты** (Google Maps, Яндекс.Карты) — локальное SEO.
- **Картинки** — оптимизация alt, имени файла.
- **Видео** — YouTube SEO.
- **Shopping** — Google Merchant Center, Яндекс.Маркет.
- **AI-поиск** (SearchGPT, Perplexity, AI Overviews) — новая воронка.
