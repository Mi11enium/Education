# Урок 37. SEO для интернет-магазина

## Особенности e-commerce SEO
- **Тысячи страниц** — карточки товаров, категории, фильтры.
- **Динамический контент** — цены, наличие, характеристики.
- **Сильная конкуренция** — почти все магазины работают в одном SERP.
- **Технические сложности** — фильтры, пагинация, дубли.

## Типы страниц в e-commerce

| Тип | Пример | SEO-важность |
|---|---|---|
| Главная | `/` | Высокая |
| Категория | `/noutbuki/` | Высокая |
| Подкатегория | `/noutbuki/igrovye/` | Средняя |
| Карточка товара | `/product/iphone-15/` | Высокая |
| Фильтр (комбинация) | `/noutbuki/?brand=asus&price=30000-50000` | Низкая |
| Бренд | `/brand/asus/` | Средняя |
| Тег | `/tag/igrovye/` | Низкая |
| Блог | `/blog/` | Средняя |

## Категории — главные коммерческие страницы

### Оптимизация
- ✅ Уникальное описание категории (500–1500 слов).
- ✅ Title и Description с ключом.
- ✅ Структура под-категорий (хлебные крошки).
- ✅ Filter/Sort без дублей.
- ✅ Schema.org/ItemList с товарами.
- ✅ BreadcrumbList.

### Текст в категории
- Общее описание категории.
- Советы по выбору.
- FAQ.
- Подборки лучших товаров.

## Карточки товаров

### Критичные элементы
- ✅ Уникальное описание (не manufacturer).
- ✅ Характеристики в таблице.
- ✅ Фото (несколько, разных ракурсов).
- ✅ Отзывы (схема AggregateRating).
- ✅ Цена, наличие, доставка.
- ✅ Сопутствующие товары.
- ✅ Breadcrumb.

### Title и Description
- Title: `[Товар] — купить по цене X ₽ | Бренд`.
- Description: с ценой, доставкой, гарантией.

### Schema.org/Product
```json
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "iPhone 15 Pro",
  "sku": "IP15-PRO-256",
  "brand": {"@type": "Brand", "name": "Apple"},
  "offers": {

    "@type": "AggregateRating",

  }

```

## Проблемы дублей в магазине

### Причины
- Фильтры: `?color=red&size=L`.
- Сортировки: `?sort=price`.
- Товары в нескольких категориях.
- Варианты: `iphone-15-red-128gb` vs `iphone-15-red-256gb`.
- Сравнение товаров.
- Корзина, wishlist с GET-параметрами.

### Решения
- ✅ Canonical на основной URL товара.
- ✅ Robots.txt: закрыть параметрические URL.
- ✅ Self-canonical для карточек.
- ✅ Noindex для результатов фильтрации (или canonical).

## Фильтрация и фасетная навигация

### Подходы
1. **JavaScript** — фильтрация без новых URL (лучший для SEO).
2. **Canonical** на категорию для всех фильтров.
3. **Noindex, follow** для фильтров.
4. **Параметрические URL с обработкой** в robots.txt.

## Пагинация
- Use **next/prev** (Google игнорирует, но не вредит).
- **Self-canonical** на каждой странице.
- **Уникальные блоки** (например, «Топ-товары на странице 3»).
- **Load more (JS)** вместо пагинации.

## Сезонность
- «Купить [товар] к 8 марта» — короткие сезонные страницы.
- Уникальный контент + подготовка за 1–2 месяца.

## Удалённые товары
- ❌ 404 — потеря трафика.
- ✅ 301 на аналогичный товар или категорию.
- ✅ Если аналогов нет — 410 Gone + объяснение.

## Инструменты
- **Screaming Frog** — аудит магазина.
- **Ahrefs/SEMrush** — конкуренты.
- **Google Merchant Center** — товарный фид.
- **Яндекс.Маркет** — для России.
