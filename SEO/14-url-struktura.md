# Урок 14. URL и структура сайта

## Анатомия URL

```
https://example.com/категория/подкатегория/страница?параметр=значение#якорь
└──┬──┘ └──┬───┘ └───┬──────┘ └────┬────┘ └────┬────┘ └┬┘
 протокол   домен     путь         файл       GET      фрагмент
```

## Правила SEO-friendly URL

### Длина и читаемость
- **До 75–90 символов** (рекомендация).
- **Короткий, понятный, читаемый**.
- Только латиница, цифры, дефисы.

### Структура
- ✅ Используйте дефис `-` для разделения слов.
- ✅ Только строчные буквы.
- ✅ Целевой ключ в URL (если возможно).
- ✅ Убрать стоп-слова: `a`, `the`, `и`, `в`, `на`.

### Примеры

✅ Хорошо:
```
example.com/blog/kak-vybrat-noutbuk
example.com/shop/iphone-15-pro
example.com/uslugi/razrabotka-saitov-moskva
```

❌ Плохо:
```
example.com/blog/post/2024/01/15/123
example.com/shop/product.php?id=4567
example.com/blog/как_выбрать_ноутбук_для_работы_в_2025_году
```

## Технические требования

### HTTPS обязателен
С 2014 года Google учитывает HTTPS как фактор ранжирования. С 2018 — без HTTPS помечает как «Незащищённое соединение».

### Канонизация URL
Один и тот же контент может быть доступен по разным URL:
- `example.com/page`
- `example.com/page/`
- `example.com/page?utm_source=fb`
- `example.com/Page` (case)

Решения:
1. **301-редирект** на канонический URL.
2. **Canonical** (см. урок 26).
3. Внутренние ссылки только на канонический URL.

### ЧПУ (человекопонятный URL)
Большинство CMS (WordPress, Bitrix, Tilda) поддерживают ЧПУ. Если нет — настройте mod_rewrite.

## Структура сайта

### 3 модели
1. **Плоская** — все страницы на одном уровне. Подходит для маленьких сайтов.
2. **Древовидная** — категории → подкатегории → страницы. Стандарт.
3. **Сетка (теги)** — перекрёстные теги. Сложнее для сканирования.

### Глубина вложенности
- **Не более 3–4 кликов** от главной до любой страницы.
- Идеально: `Главная → Категория → Подкатегория → Товар/Статья`.

### Пример структуры интернет-магазина
```
/                      — главная
/shop/                 — каталог
/shop/noutbuki/        — категория
/shop/noutbuki/igrovye/— подкатегория
/shop/noutbuki/igrovye/asus-rog-strix-g15 — товар
/blog/                 — блог
/blog/kak-vybrat-noutbuk — статья
/contact/              — контакты
/about/                — о компании
```

## URL для блогов
- `/blog/post-name/` или `/category/post-name/`.
- Избегайте дат в URL (снижает актуальность).
- После изменения URL — настройте 301-редирект.

## Чек-лист урока
- [ ] URL короткий, читаемый, без стоп-слов.
- [ ] Только латиница, дефисы, цифры.
- [ ] Целевой ключ в URL.
- [ ] Глубина не более 3–4 кликов от главной.
- [ ] HTTPS.
