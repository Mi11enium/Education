# Урок 42. Яндекс.Вебмастер

## Что это
**Яндекс.Вебмастер** — аналог GSC от Яндекса.

`https://webmaster.yandex.ru`

## Регистрация
- Подтверждение через HTML-файл, DNS, Meta-тег, WHOIS.
- Регион сайта.
- Связь с Яндекс.Метрикой.

## Основные разделы

### 1. Мониторинг → Сводка
- Показы, клики, CTR.
- Индексирование.
- Динамика за период.

### 2. Мониторинг → Поисковые запросы
- По каким запросам показывается сайт.
- Позиции, клики, CTR.
- Фильтр по страницам.

### 3. Мониторинг → Важные страницы
- Статус конкретных URL.
- Включены ли в индекс.
- Какие страницы выбрал Яндекс как важные.

### 4. Индексирование → Статистика обхода
- Сколько страниц робот обходит в день.
- Тренд.

### 5. Индексирование → Страницы в поиске
- Сколько страниц в индексе.
- Динамика.

### 6. Индексирование → Исключённые страницы
- Причины исключения:
  - 4xx/5xx.
  - Canonical.
  - Noindex.
  - Дубли.
  - Редирект.

### 7. Файлы Sitemap
- Загруженные карты сайта.
- Статус и количество URL.

### 8. Диагностика → robots.txt
- Проверка корректности.
- Тест доступности страниц.

### 9. Диагностика → Переопределение (canonical)
- Какие страницы Яндекс считает каноническими.
- Иногда отличается от ваших canonical.

### 10. Внешние ссылки
- Топ доноров.
- Анкоры.

### 11. Безопасность
- Взлом.
- Подозрительный код.

### 12. Фильтры
- Минусинск (за покупные ссылки).
- АГС (за качество контента).
- ⚠️ Если сайт под фильтром — нужно решать.

### 13. Уведомления
- Важные события (ошибки, фильтры).

### 14. Переезд сайта
- Переезд на новый домен.
- HTTP → HTTPS.

### 15. Оригинальные тексты
- Защита контента (приоритет публикации).
- Яндекс фиксирует время отправки.

## Полезные инструменты

### Оригинальные тексты
Перед публикацией статьи отправьте текст в Вебмастер → Оригинальные тексты → добавить.
Яндекс зафиксирует, что **вы** первый опубликовали → приоритет в случае копипаста.

### Турбо-страницы
Устаревший формат (Яндекс закрыл поддержку с 2023).

### Переезд
- Пошаговая инструкция при смене домена.
- Уведомления о завершении переезда.

## Анализ

### Регулярные задачи
1. Проверить Сводку.
2. Мониторинг запросов → топ-страницы по позициям.
3. Ошибки индексирования.
4. Новые ссылки.

### Диагностика проблем
- «Страница не в индексе» → раздел Исключённые страницы.
- «Позиции упали» → сравнить с прошлым месяцем, проверить фильтры.
- «Нет трафика» → проверить robots.txt и индексирование.

## Регионы
- В Вебстере можно указать регионы.
- Полезно для локального бизнеса.
