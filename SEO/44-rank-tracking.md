# Урок 44. Rank Tracking и мониторинг позиций

## Что такое rank tracking
**Rank tracking** — отслеживание позиций сайта по целевым запросам в поисковой выдаче.

## Зачем
- Понимать динамику (рост / падение).
- Реагировать на изменения.
- Оценивать эффективность оптимизации.
- Сравнивать с конкурентами.
- Отчитываться перед клиентом / руководством.

## Инструменты

### Платные (специализированные)
| Инструмент | Особенность | Цена |
|---|---|---|
| Топвизор | РФ, точные позиции, кластеризация | ~2000 ₽/мес |
| Serpstat | РФ + мир, keyword research | $69/мес |
| SE Ranking | Универсальный, доступный | $65/мес |
| Ahrefs | Мир, очень большой охват | $99/мес |
| SEMrush | Универсальный, с PPC | $130/мес |
| AccuRanker | Быстрый, API | $109/мес |
| ProRankTracker | Бюджетный | $65/мес |

### Бесплатные (ограниченно)
- **Google Search Console** — «средняя позиция» агрегированная.
- **Яндекс.Вебмастер** — позиции по запросам.
- **PixelPlus, Arsenkin.ru** — частично бесплатно.

## Как настроить

### Шаг 1. Собрать ядро
Семантическое ядро (список целевых запросов).

### Шаг 2. Группировка
По разделам, по интенту, по страницам (mapping).

### Шаг 3. Настройка в инструменте
- Поисковая система (Google/Yandex).
- Регион (Москва, СПб, и т.д.).
- Устройство (desktop/mobile).
- Язык.
- Частота проверки.

### Шаг 4. Конкуренты
Добавьте конкурентов для сравнения.

### Шаг 5. Регулярный мониторинг
- Еженедельно или чаще для важных запросов.
- Раз в месяц для общего охвата.

## Что отслеживать

### Метрики
- **Позиция** (текущая, динамика).
- **Видимость** (% от топ-1).
- **SERP features** — Featured Snippet, PAA, карты.
- **SERP-пейзаж** — кто в топе, какие форматы.

### Сегменты
- Брендовые vs небрендовые.
- Информационные vs коммерческие.
- High-priority vs второстепенные.

## Регулярные отчёты

### Что включать
1. Изменение позиций за неделю/месяц.
2. Топ-3 роста и падения.
3. Видимость в динамике (график).
4. Сравнение с конкурентами.
5. SERP-features (что попало в сниппет).
6. Гипотезы и план действий.

### Дашборд
- **Google Sheets** + API инструмента.
- **Looker Studio (Data Studio)** — подключить данные.
- **Яндекс.Метрика / GA4** — трафик.

## Mobile vs. Desktop
- Позиции часто **разные**.
- Отслеживайте оба (Google Mobile-First Index).
- Иногда десктоп №1, мобильный №7.

## Геозависимость
- Москва ≠ СПб ≠ Казань.
- Создавайте отдельные трекеры для разных регионов.
- Или используйте «геонезависимый» трекер.

## Что делать при падении позиций

### Чек-лист
1. Изменения на сайте (новые 301, noindex, удаления).
2. Технические проблемы (скорость, CWV).
3. Апдейты алгоритма Google.
4. Сезонность.
5. Действия конкурентов.
6. Качество бэклинков.
7. Качество контента.
8. Поведенческие факторы.

### Что делать
- Проверить GSC → Покрытие.
- Проверить Core Web Vitals.
- Сравнить с конкурентами в SERP.
- Обновить контент.
- Усилить перелинковку.
- Нарастить ссылки.

## Anti-rank-tracking ловушки

### Персонализация
Google учитывает историю, локацию, поведение — реальные пользователи видят **другую** выдачу. Rank tracker показывает «нейтральную».

### Прокси и API
Для точности — прокси с IP нужных регионов или API SERP (SerpAPI, SerpDog).

### Частота проверки
⚠️ Не проверяйте один запрос тысячу раз в день — Google может показывать CAPTCHA или «аномальную» выдачу.
