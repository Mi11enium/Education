# Урок 2. Как работают поисковые системы

## Три главных этапа работы ПС
1. **Crawling (обход)** — поисковый робот (краулер, бот, паук) обходит страницы по ссылкам.
2. **Indexing (индексирование)** — содержимое страниц анализируется и сохраняется в базе (индексе).
3. **Ranking (ранжирование)** — алгоритмы сортируют страницы по релевантности запросу.

## Кто такие краулеры
- **Googlebot** — основной бот Google.
- **YandexBot** — основной бот Яндекса.
- **Bingbot** — бот Microsoft Bing.
- **DuckDuckBot** — бот DuckDuckGo.

Краулеры следуют по ссылкам, читают `robots.txt`, `sitemap.xml` и мета-теги.

## Что такое индекс
Это гигантская база данных, где хранятся:
- URL страниц.
- Содержимое (текст, мета-теги, alt-картинок).
- Сигналы (скорость, mobile-friendly, безопасность).

Если страницы нет в индексе — её не существует для поиска.

## Факторы ранжирования Google (упрощённо)
| Группа | Примеры факторов |
|---|---|
| Контент | Релевантность, качество, E-E-A-T, свежесть |
| Бэклинки | Количество, качество, анкоры, тематика |
| Технические | Скорость, mobile-friendly, HTTPS, Core Web Vitals |
| Поведенческие | CTR, время на сайте, отказы |
| Контекстные | Локация, язык, тип устройства, история |

## Как Google оценивает качество (E-E-A-T)
- **Experience** — реальный опыт автора.
- **Expertise** — экспертиза в теме.
- **Authoritativeness** — авторитетность (ссылки, упоминания).
- **Trustworthiness** — надёжность (HTTPS, источники, политика).

## Что контент-менеджер должен знать о ПС
- Скорость индексации новой страницы — от нескольких минут до нескольких недель.
- PageRank передаётся через внутренние и внешние ссылки.
- Поисковики не видят Flash, плохо видят JS-контент (нужен рендеринг).
- Дубли и тонкий контент отбрасываются или понижаются.
