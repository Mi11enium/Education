# Урок 6. Ключевые слова и поисковый интент

## Что такое ключевое слово
**Ключевое слово (keyword)** — это слово или фраза, которую пользователь вводит в поисковую строку. По нему ПС определяет релевантность страниц.

**Поисковый интент (search intent)** — цель, которую пользователь хочет достичь с помощью запроса.

## 4 типа интента

### 1. Информационный (Informational)
Цель — узнать/понять/научиться.
Маркеры: "что такое", "как", "почему", "инструкция", "рецепт", "определение".
Примеры: "как настроить robots.txt", "что такое canonical".

### 2. Навигационный (Navigational)
Цель — найти конкретный сайт/страницу.
Маркеры: название бренда, "вход", "официальный сайт", "личный кабинет".
Примеры: "вконтакте", "google search console".

### 3. Коммерческий (Commercial Investigation)
Цель — сравнить перед покупкой.
Маркеры: "лучший", "рейтинг", "обзор", "топ-10", "vs", "сравнение", "купить".
Примеры: "лучший ноутбук для работы 2025", "iphone 15 vs samsung s24".

### 4. Транзакционный (Transactional)
Цель — купить/заказать/подписаться.
Маркеры: "купить", "заказать", "цена", "стоимость", "доставка".
Примеры: "купить iphone 15 в москве", "заказать сайт под ключ".

## Как определять интент
1. Смотрите SERP — что показывает ПС по запросу?
   - Интернет-магазин → транзакционный.
   - Статья / гайд → информационный.
   - Сравнение / рейтинг → коммерческий.
   - Домашняя страница бренда → навигационный.
2. Смотрите слова-маркеры.
3. Используйте кластеризацию по SERP (например, Serpstat).

## Матрица «интент × тип страницы»

| Интент | Подходящий тип страницы |
|---|---|
| Информационный | Блог-статья, гайд, FAQ |
| Навигационный | Главная, раздел, страница бренда |
| Коммерческий | Категория, обзор, рейтинг, сравнение |
| Транзакционный | Карточка товара, страница услуги, лендинг |

## Важные правила
- Один ключ — один интент — одна страница.
- Несколько интентов → нужны разные страницы или правильная структура.
- Google понимает интент через поведение пользователей в SERP.
