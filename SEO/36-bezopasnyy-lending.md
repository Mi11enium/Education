# Урок 36. On-Page SEO для лендингов

## Что такое лендинг
**Лендинг (landing page)** — страница с одной конкретной целью (заявка, покупка, регистрация).

Виды:
- **Продающий** — для прямой продажи.
- **Лид-магнит** — собирает контакты (в обмен на полезность).
- **Пресейл** — промежуточный (презентует перед основным предложением).
- **Подписная страница** — email-подписка.
- **Под меркамент** — под конкретную рекламную кампанию.

## Особенности SEO для лендингов

### Плюсы
- ✅ Сильный коммерческий интент → хороший ROI.
- ✅ Одна цель → высокая конверсия.
- ✅ Можно оптимизировать под конкретные запросы.

### Минусы
- ❌ Часто «голый» — мало текста.
- ❌ Высокая конкуренция.
- ❌ Может плохо ранжироваться по информационным ключам.

## Структура лендинга для SEO

### Title
`[Услуга/товар] — купить в [город] от [цена] ₽ | Бренд`
`[Услуга] под ключ — заказать с гарантией | Бренд`

### Description
`Закажите [услугу] по цене от X ₽. Гарантия, опыт N лет, отзывы. Доставка/выезд по [городу].`

### H1
- Должен быть понятным и обещать выгоду.
- Часто: «[Услуга] — быстро, качественно, недорого».

### Основные блоки
1. **Hero (первый экран)** — оффер + CTA + изображение.
2. **Проблема и решение** — боль клиента.
3. **Преимущества** — почему мы.
4. **Как работаем** — этапы.
5. **Кейсы и отзывы** — доказательства.
6. **Цены** — тарифы.
7. **FAQ** — частые вопросы (важно для SEO + Schema!).
8. **Форма заявки** — CTA.
9. **Контакты** — телефон, адрес, карта.

## SEO-элементы

### Schema-разметка
- `Organization` — компания.
- `LocalBusiness` — для локального бизнеса.
- `Product`/`Service` — что предлагаете.
- `FAQPage` — блок вопросов.
- `AggregateRating` — отзывы.
- `BreadcrumbList` — хлебные крошки.

### Контент
- ✅ 800–1500+ слов текста (для SEO).
- ✅ LSI-слова, естественно распределённые.
- ✅ Ответы на частые вопросы.
- ✅ Таблица сравнения тарифов.

### Изображения
- Hero-картинка с alt.
- Скриншоты работ.
- Видео-отзывы.

## Оптимизация под коммерческие запросы

### High Intent ключи
- «купить», «заказать», «цена».
- «в [городе]», «с доставкой».
- «от производителя», «оптом».

### Кластеризация запросов
- Несколько лендингов под разные интенты.
- Лендинг под каждый город (если нужна геопривязка).

## Технические моменты

### PageSpeed
- Лендинг должен быть быстрым (≤2 сек LCP).
- Минимум JS, оптимизированные изображения.

### Mobile
- Обязательно адаптивный.
- CTA-кнопки крупные.

### Tracking
- Установлены цели (GA4, Яндекс.Метрика).
- Conversion events на формы.
- Heatmap (Hotjar, Microsoft Clarity).

## Лендинг под рекламу vs. под SEO

| Параметр | Под рекламу | Под SEO |
|---|---|---|
| Объём текста | 200–500 слов | 1000–2500 слов |
| Стиль | Яркий, продающий | Информативный + продающий |
| Акцент | Оффер, CTA | Покрытие ключей, FAQ |
| Блоки | Минимум | Полная структура |
| Бюджет на оптимизацию | Низкий | Высокий |

## Чек-лист лендинга
- [ ] Title и Description с ключом и CTA.
- [ ] H1 понятный, обещает выгоду.
- [ ] Минимум 800 слов уникального текста.
- [ ] FAQ с Schema.
- [ ] Social proof (отзывы, кейсы, цифры).
- [ ] CTA в нескольких местах.
- [ ] Быстрый (PageSpeed > 70).
- [ ] Mobile-friendly.
- [ ] Установлены цели в аналитике.
- [ ] Breadcrumbs.

## Чек-лист урока
- [ ] Лендинг имеет SEO-friendly структуру.
- [ ] Есть блок FAQ с Schema.
- [ ] Текста достаточно для ранжирования.
- [ ] Используются high-intent ключи.
- [ ] Установлена аналитика и цели.
