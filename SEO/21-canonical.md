# Урок 21. Canonical: канонические URL

## Что это
**Canonical URL** — это «главная» версия страницы, которую вы указываете поисковикам. Используется, когда один и тот же контент доступен по нескольким URL.

```html
<link rel="canonical" href="https://example.com/page/" />
```

## Зачем нужен

### Проблема дублей
Дубли могут возникать из-за:
- Параметров URL: `?color=red`, `?sort=price`.
- Регистра: `/Page` vs `/page`.
- Слэша в конце: `/page` vs `/page/`.
- Версий: HTTP vs HTTPS, www vs без www.
- Категорий: товар в нескольких категориях.
- Контентных копий (синонимы).

Дубли без решения размывают PageRank и могут привести к «угадыванию» ПС неправильной версии.

## Как использовать

### Rel=canonical
```html
<head>
  <link rel="canonical" href="https://example.com/page/" />
</head>
```

### Правила
- ✅ Указывайте на каждой странице.
- ✅ Абсолютный URL.
- ✅ HTTPS-версия.
- ✅ Self-canonical (можно ссылаться на саму себя — это нормально).
- ✅ Одна каноническая версия на страницу.

### Canonical на другой URL (не дубль)
Google учитывает canonical только если:
- Указанный URL **доступен** (не 404).
- Указанный URL **не заблокирован** в robots.txt.
- Указанный URL **содержит похожий контент**.
- Согласован с сигналами (HTTP-код, sitemap, hreflang).

## Canonical vs. 301-редирект

| Ситуация | Решение |
|---|---|
| Страница навсегда переехала | **301** + canonical |
| Дубль одного контента | **canonical** |
| Точная копия | **301** или canonical |
| Контент немного отличается | canonical на основную |
| Разный контент на разных URL | **Не ставить canonical!** |

## Где указывать

1. **HTML `<head>`** — основной способ.
2. **HTTP-заголовок** `Link: <https://example.com/page/>; rel="canonical"` — для не-HTML файлов (PDF).
3. **Sitemap** — указывайте только канонические URL.
4. **AMP-версия** — canonical указывает на десктоп-версию.

## Cross-domain canonical
```html
<link rel="canonical" href="https://publisher.com/article/" />
```
Можно указать каноническую версию на другом домене (например, syndication).

## Частые ошибки

❌ Canonical на 404 / закрытую страницу → Google игнорирует.
❌ Canonical на неиндексируемую страницу.
❌ Canonical на страницу с другим контентом.
❌ Canonical с относительным URL (`/page/` вместо `https://...`).
❌ Canonical HTTP → HTTPS противоречит редиректу.
❌ Несколько canonical-тегов на странице.

## Как проверить
- Просмотр кода страницы (`Ctrl+U`).
- **Screaming Frog** — массово.
- **Siteliner** — поиск дублей контента.

## Чек-лист урока
- [ ] На каждой странице есть canonical-тег.
- [ ] Canonical абсолютный, HTTPS.
- [ ] Нет противоречий с редиректами.
- [ ] Canonical указывает на похожий контент.
