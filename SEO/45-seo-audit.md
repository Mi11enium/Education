# Урок 45. SEO-аудит сайта

## Что такое SEO-аудит
**SEO-аудит** — комплексная проверка сайта по всем направлениям SEO с целью найти проблемы и точки роста.

## Когда проводить
- ✅ Каждые 3–6 месяцев.
- ✅ После редизайна / переезда.
- ✅ При резком падении трафика.
- ✅ При смене CMS.
- ✅ Перед запуском нового направления.

## Структура аудита

### 1. Технический аудит

#### Индексация
- Сканирование полного сайта (Screaming Frog, Sitebulb).
- Сколько страниц в индексе Google/Яндекс.
- Какие страницы исключены и почему.
- Robots.txt корректен.
- Sitemap актуален.

#### Скорость и CWV
- PageSpeed Insights для ключевых страниц.
- Core Web Vitals (CrUX данные).
- TTFB.

#### Мобильность
- Mobile-friendly тест.
- Mobile PageSpeed.
- Responsive vs отдельный m-сайт.

#### HTTPS и безопасность
- Все страницы по HTTPS.
- Нет mixed content.
- HSTS.
- Нет malware.

#### Структура URL
- Читаемые URL.
- Canonical настроен.
- Нет дублей.

#### Редиректы
- 301 для всех переездов.
- Нет цепочек.
- Нет soft 404.

#### Schema и мета-теги
- Уникальные Title, Description.
- Иерархия H1–H6.
- Schema на нужных страницах.

### 2. On-Page аудит

#### Контент
- Объём текстов.
- Уникальность.
- E-E-A-T сигналы.
- Актуальность.

#### Ключевые слова
- Покрытие семантики.
- Плотность ключей (естественность).
- LSI использование.

#### Перелинковка
- Внутренние ссылки (Screaming Frog).
- Орфанные страницы.
- Битые ссылки.

#### Alt-теги
- Наличие и качество.
- Дубли alt.

### 3. Off-Page аудит

#### Бэклинки
- Количество и качество.
- Анкорный профиль.
- Токсичные ссылки.
- Динамика роста.

#### Упоминания
- Бренд упомянут без ссылки.

### 4. Контент-аудит

#### Категоризация страниц
- Хорошие (трафик + позиции).
- Требуют улучшения (тонкие, нет трафика).
- Дубли.
- Удалить.

#### Тематические пробелы
- Какие темы не покрыты.
- Конкуренты покрывают, а мы нет.

### 5. Юзабилити (UX)
- Навигация.
- Скорость.
- Мобильный UX.
- CTA-видимость.

### 6. Локальный аудит (для локального бизнеса)
- GBP заполнен.
- NAP-консистентность.
- Отзывы.
- Локальные ссылки.

### 7. Аналитика
- GSC и Я.Вебмастер настроены.
- GA4 / Метрика корректно отслеживают конверсии.
- Цели настроены.

## Инструменты аудита

### Автоматические (платные)
- **Ahrefs Site Audit** — подробный.
- **SEMrush Site Audit**.
- **Serpstat Audit**.
- **Screaming Frog SEO Spider** — основной.

### Бесплатные
- **Google Search Console**.
- **Google PageSpeed Insights**.
- **Google Mobile-Friendly Test**.
- **Schema.org Validator**.
- **Screaming Frog** (до 500 URL бесплатно).

### Ручные
- Просмотр SERP.
- Просмотр конкурентов.
- Тест форм, регистрации, корзины.

## Отчёт аудита

### Структура
1. **Резюме** — топ-5 главных проблем.
2. **Детальные находки** — по разделам.
3. **Приоритеты** — что делать в первую очередь.
4. **План работ** — таблица с задачами, ответственными, сроками.
5. **Метрики успеха** — как отслеживать.

### Формат
- Google Sheets / Excel + Google Docs / PDF.
- Дашборд в Looker Studio.
- Task tracker (Jira, Asana, Notion).

## Приоритизация

### Срочно / важно
- Падение трафика.
- Технические ошибки индексации.
- Санкции Google.

### Важно / не срочно
- Тонкий контент.
- Неоптимизированные мета-теги.
- Скорость.

### Не срочно / не важно
- Косметика.
- Лонгриды на темы с нулевым спросом.

## Чек-лист урока
- [ ] Аудит проводится каждые 3–6 месяцев.
- [ ] Используете Screaming Frog + Ahrefs/SEMrush.
- [ ] Отчёт включает технический + on-page + off-page.
- [ ] Есть приоритизация задач.
- [ ] Сформирован план работ с ответственными.
