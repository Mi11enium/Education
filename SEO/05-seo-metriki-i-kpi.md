# Урок 5. SEO-метрики и KPI

## Иерархия метрик

### Уровень 1 — Видимость
- **Позиции (rank position)** — место сайта в выдаче по запросу.
- **Видимость (visibility)** — % показов относительно топ-конкурентов.
- **Количество запросов в топ-10/топ-3/топ-1**.

### Уровень 2 — Трафик
- **Органические сессии** (GA4).
- **Органические пользователи** (уникальные).
- **Показы и CTR** (Google Search Console).

### Уровень 3 — Поведение
- **Время на странице**.
- **Глубина скролла**.
- **Показатель отказов** (Bounce Rate).
- **Engaged sessions** (в GA4 — сессии >10 сек или с событиями).

### Уровень 4 — Бизнес-результат
- **Лиды** с органики.
- **Заявки / продажи** (атрибуция!).
- **ROI SEO** = (доход − затраты) / затраты × 100%.

## Основные KPI контент-менеджера

| KPI | Цель |
|---|---|
| Количество новых оптимизированных страниц | Рост индекса |
| Средняя позиция по целевым запросам | Топ-10 |
| Органический трафик на страницу | Рост месяц к месяцу |
| CTR в выдаче | >5% для топ-10 |
| Покрытие ключами (keyword coverage) | % целевых запросов в топ-50 |

## Как отслеживать позиции
- **Google Search Console** — бесплатно, "средняя позиция" агрегированная.
- **Топвизор, Serpstat, SE Ranking, Ahrefs, SEMrush** — точные позиции по ядру.
- **Яндекс.Вебмастер** — для Яндекса.

## Атрибуция: что считать «органикой»
- **Last non-direct click** — стандарт GA4.
- **First-click** — если SEO привёл клиента впервые.
- **Data-driven attribution** — алгоритмическая модель (нужен объём данных).

## Анти-метрики (что НЕ считать успехом)
❌ Только количество текстов без учёта трафика.
❌ Позиции без учёта CTR.
❌ Трафик без учёта конверсий.
❌ Сырые «показы» в GSC без кликов.

## Дашборд для отчёта
1. Видимость (топвизор/serpstat).
2. Органический трафик (GA4).
3. Целевые лиды / заявки (CRM + GA4).
4. Техническое здоровье (GSC: покрытие, ошибки).

## Чек-лист урока
- [ ] Различаете метрики видимости, трафика, поведения и бизнеса.
- [ ] Знаете свои KPI как контент-менеджера.
- [ ] Понимаете, что «позиции» без «трафика» и «конверсий» — не метрика успеха.
