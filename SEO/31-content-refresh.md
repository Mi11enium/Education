# Урок 31. Обновление контента (Content Refresh)

## Зачем обновлять
- **Freshness signal** — Google любит свежий контент.
- Новые данные, факты, исследования.
- Новые ключи (тренды).
- Улучшение позиций и CTR.
- Защита от каннибализации.

## Когда обновлять
1. **Потеря позиций** — статья падает, проверьте.
2. **Устарели данные** — статистика, цены, даты, имена.
3. **Появились новые под-темы** — Google Trends, PAA.
4. **Раз в 6–12 месяцев** — профилактика для топовых материалов.
5. **Смена алгоритма** — после апдейтов Google.

## Процесс обновления

### Шаг 1. Аудит
- Проверьте позиции (Топвизор, GSC).
- Сравните с конкурентами в SERP.
- Найдите слабые места (тонкий контент, нет FAQ, плохая структура).

### Шаг 2. Что обновлять
- **Title / Description** — свежие формулировки.
- **Добавить объём** — раскрыть недостающие подтемы.
- **Актуализировать данные** — года, цены, скриншоты.
- **Добавить FAQ** — на основе PAA.
- **Новые ключи** — LSI, long-tail.
- **Новые ссылки** — внутренние, внешние.
- **Мультимедиа** — видео, новые фото.

### Шаг 3. Обновление сигналов
- Обновите `<meta name="article:modified_time">`.
- Обновите дату на странице (видимую).
- Schema.org `dateModified`.
- `<lastmod>` в sitemap.

### Шаг 4. Перепубликация
- Поменяйте URL только если нужно (или сохраните).
- Оптимизируйте заново по чек-листу on-page.
- Проверьте индексацию (URL Inspection в GSC).

## Типы обновлений

### Косметические
- Замена фото.
- Обновление года в Title.
- Исправление опечаток.

### Средние
- Добавление 500–1000 слов.
- FAQ блок.
- Новые внутренние ссылки.

### Глубокие (rewrite)
- Полная переработка.
- Смена структуры.
- 2x–3x объёма.

## Контент, который лучше удалить
Если после обновления статья не приносит пользы — лучше удалить (410) или объединить с другой.

## Дата публикации vs. обновления

### Что показывать
- **Date published**: первая публикация.
- **Date modified**: последнее обновление.
- Обе даты должны быть видны на странице.

### Как Google их использует
- Freshness signal учитывает `dateModified` в Schema.
- Title с годом («Топ-10 в 2025») привлекает внимание.
- Слишком частое обновление без причины — не помогает.

## Практический чек-лист обновления

1. [ ] Проверить позиции и CTR.
2. [ ] Сравнить с топ-3 конкурентами.
3. [ ] Актуализировать данные, даты, цены.
4. [ ] Добавить новые H2/H3 из PAA.
5. [ ] Расширить объём (до среднего по топу).
6. [ ] Обновить alt, Title, Description.
7. [ ] Добавить FAQ со Schema.
8. [ ] Перелинковать с новыми материалами.
9. [ ] Обновить Schema (dateModified).
10. [ ] Проверить индексацию через 1–2 недели.

## Чек-лист урока
- [ ] Топовые материалы обновляются каждые 6–12 месяцев.
- [ ] Видны обе даты — публикации и обновления.
- [ ] Schema.org dateModified актуален.
- [ ] Обновление = реальное улучшение, не косметика.
