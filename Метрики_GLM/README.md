# Шпаргалки: 20 уроков по метрикам для контент-менеджера маркетплейсов

Структура: 1 урок = 1 md-шпаргалка + 1 xlsx-тренажёр (папка `тренажёры/`).
Все числа в тренажёрах считаются по одному сквозному примеру: SKU «Комплект постельного белья 2-спальный (сатин)», цена 2350 ₽, комиссия 15%, себестоимость 950 ₽, реклама 180 ₽/шт → прибыль ≈ 780,5 ₽/шт.

## Как работать
1. Читаете md-урок (2–4 минуты).
2. Открываете соответствующий `тренажёр-NN-*.xlsx`: лист «Условия» → лист «Задания» → вписываете ответы в жёлтые ячейки, столбец «Статус» проверяет автоматически.
3. Лист «Справка» — формулы урока одним экраном.
