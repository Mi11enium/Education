# Урок 20: Еженедельный дашборд контент-менеджера: 12 метрик на 1 экран

Соберите все уроки в одну таблицу контроля раз в неделю по A-SKU и раз в месяц — по каталогу.

## 12 рычажков дашборда
| # | Метрика | Сигнал внимания |
|---|---|---|
| 1 | Прибыль/шт | упала ниже 500 ₽ — пересчитать экономику |
| 2 | Маржинальность % | < 10% — стоп закупки |
| 3 | ДРР % | > маржа % — резание ставок |
| 4 | CTR % | ниже нормы категории — обложка |
| 5 | CVR % | ниже 3–4% — «внутрянка» |
| 6 | Позиция ключевая | Выход из топ-10 по средне-част. — вверх по SEO |
| 7 | Скорость шт/день | −3 недели подряд вниз — промо |
| 8 | Дни запаса | > 60 — промо; < 15 — дозаказ |
| 9 | OOS % | > 2% — разбираться |
| 10 | % возвратов | > 12% — карта причин |
| 11 | Рейтинг | падение > 0,2 за 7 дн — разбор негатива |
| 12 | Доля органики | < 60% — усилить SEO/рекламу |

## Ритм работы
- **Пн:** дашборд недели → 2–3 вывода;
- **Ср:** проверка реклам и цен по выводам;
- **Пт:** фиксация «что изменилось», удалённый прогноз WoW.

## Правило 80/20
Смотрите в первую очередь на 2–3 сторожевых метрики, где сейчас боль. Дашборд из 20+ строк не читается; все «вторичные» метрики — раз в месяц.
